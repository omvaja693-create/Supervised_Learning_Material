Section 01Overview

“Accuracy 95%” Enough Nahi Hai

Classification model ka evaluation sirf correct predictions count karne se complete nahi hota. Humein samajhna hota hai: model ne positive ko kitna correctly pakda, negative ko kitna safely reject kiya, aur kis type ki galti ki.

Fraud detection, medical screening, spam filtering aur churn prediction mein different errors ki cost different hoti hai. Isi liye metric selection problem context par depend karta hai.

Core IdeaActual label aur predicted label ko compare karke confusion matrix banti hai. Confusion matrix se accuracy, precision, recall, F1 aur report metrics derive hote hain.
Confusion MatrixPrecisionRecallROC-AUC
🛡️ Non-Technical Example

Security guard suspicious person ko identify karta hai. Innocent person ko suspicious bolna Type 1 error hai; dangerous person ko innocent samajhna Type 2 error hai. Kaunsi galti zyada costly hai, uske basis par metric priority decide hogi.

Section 025 W's Framework

What?

Predictions ko actual labels ke against measure karne ke methods.

Why?

Model reliable hai ya dangerous pattern miss kar raha hai, ye samajhne ke liye.

When?

Training ke baad validation/test set par; deployment monitoring mein bhi.

How?

Confusion matrix, threshold, probability ranking aur metric formulas se.

Where?

Medical, fraud, search, recommendations, credit, spam and quality inspection.

Who?

Data scientist metric calculate karta hai; domain expert cost and threshold choose karta hai.

Section 03Type 1 and Type 2 Errors

ErrorAlso calledMeaningExample
Type 1False Positive (FP)Actual negative ko positive predict karnaGood email ko spam bolna
Type 2False Negative (FN)Actual positive ko negative predict karnaFraud transaction miss karna

Type 1 reduce karna

Precision improve karne ke liye threshold increase kar sakte hain, but some positives miss ho sakte hain.

Type 2 reduce karna

Recall improve karne ke liye threshold lower kar sakte hain, but more false alarms aa sakte hain.

Trade-offThreshold change karne se usually precision-recall balance shift hota hai. “Best” threshold domain cost ke bina define nahi hota.

Section 05Accuracy

Accuracy formulaAccuracy=TP+TNTP+TN+FP+FN

Accuracy batati hai total predictions mein kitne correct the. Balanced classes aur comparable error costs mein useful hai.

Imbalance trapAgar 99% samples negative hain aur model har sample ko negative bolta hai, accuracy 99% aa sakti hai, but positive class recall 0% hoga. Isliye accuracy alone misleading ho sakti hai.
🎯

Section 06Precision and Recall

Precision: Predicted Positive ki Quality

Precision=TPTP+FP

Model ne jitno ko positive bola, unmein actually kitne positive the? False alarms reduce karne par precision improve hoti hai.

Recall: Actual Positive ki Coverage

Recall=TPTP+FN

Total actual positives mein se model ne kitne catch kiye? Missed positives reduce karne par recall improve hoti hai.

🩺 Context Choice

Medical screening mein disease miss karna costly ho sakta hai, so recall priority. Spam filter mein genuine email ko spam bolna costly ho sakta hai, so precision priority.

⚡

Section 07F1 Score

Harmonic meanF1=2×Precision×RecallPrecision+Recall

F1 precision aur recall ka harmonic mean hai. Ye tab useful hai jab dono ko reasonably high rakhna ho, especially imbalanced classification mein.

Harmonic mean kyon? Agar precision 0.95 but recall 0.10 hai, F1 low rahega. Ek metric ko ignore karke high score banana difficult hota hai.

Section 09ROC-AUC Score

Thresholds ke Across Ranking Quality

ROC curve different thresholds par True Positive Rate (TPR) aur False Positive Rate (FPR) plot karti hai.

RatesTPR=TPTP+FN,FPR=FPFP+TN

AUC ≈ 1.0

Excellent ranking: positives generally negatives se higher score paate hain.

AUC ≈ 0.5

Random ranking jaisa behavior.

AUC < 0.5

Ranking reverse ho sakti hai; model/check labels inspect karo.

ImportantROC-AUC threshold-independent ranking view hai. Highly imbalanced positive class mein PR-AUC bhi consider karo.

Section 11Python Implementation

classification_metrics.py
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score from sklearn.metrics import confusion_matrix, classification_report, roc_auc_score y_prob = model.predict_proba(X_test)[:, 1] y_pred = (y_prob >= 0.50).astype(int) print("Accuracy:", accuracy_score(y_test, y_pred)) print("Precision:", precision_score(y_test, y_pred)) print("Recall:", recall_score(y_test, y_pred)) print("F1:", f1_score(y_test, y_pred)) print("ROC-AUC:", roc_auc_score(y_test, y_prob)) print(confusion_matrix(y_test, y_pred)) print(classification_report(y_test, y_pred))
ROC-AUC ke liye hard labels nahi, positive-class probabilities/scores use karo.
roc_curve.py
from sklearn.metrics import roc_curve, roc_auc_score fpr, tpr, thresholds = roc_curve(y_test, y_prob) auc_value = roc_auc_score(y_test, y_prob) print(f"AUC = {auc_value:.3f}")
roc_curve() har threshold par FPR/TPR points deta hai; AUC in points ka aggregate ranking score hai.

🏆 Final Summary

  • Type 1 error false positive; Type 2 error false negative.
  • Accuracy overall correctness hai, but imbalance mein misleading ho sakti hai.
  • Precision predicted positives ki quality; recall actual positives ki coverage.
  • F1 precision-recall ka harmonic mean hai.
  • Confusion matrix and classification report per-class behavior reveal karte hain.
  • ROC-AUC thresholds ke across positive-vs-negative ranking quality measure karta hai.
