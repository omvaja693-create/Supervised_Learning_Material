The Line Equation — Model Kya Predict Karta Hai?
+30 XP on scroll
Core Idea — Ek Line Mein
Simple Linear Regression mein model ek straight line dhundta hai jo data ke sabse paas ho — aur us line ko use karke naye X values ke liye y predict karta hai.

Ye line ek simple equation follow karti hai — school mein padha tha: y = mx + c. ML mein ise thoda alag likhte hain!
PREDICTION EQUATION
ŷ = β₀ + β₁ × X
pronounced: "y-hat equals beta-zero plus beta-one times X"
ŷPredicted output (jo model bolega) — "y-hat"
XInput feature (jo hum model ko dete hain)
β₀Intercept — jab X=0 ho tab y ki value ("beta-zero")
β₁Slope — X mein 1 unit change se y mein kitna change ("beta-one")
School Math se ML tak — Do Notations
School (Geometry):
y = mx + c
m = slope (dhai), c = intercept (kahan shuru)
Machine Learning:
ŷ = β₀ + β₁X
β₀ = intercept (c ka ML version), β₁ = slope (m ka ML version)

Difference sirf notation ka hai — math bilkul same hai! ML mein β (beta) isliye use karte hain kyunki multiple features hone par β₀, β₁, β₂… easy notation hoti hai.
Concrete Example — Zomato Delivery Time
Real Numbers ke Saath Samjho
Maan lo model ne seekha:  delivery_time = 8 + 9 × distance

Yaani: β₀ = 8 (restaurant prep time — distance zero ho tab bhi 8 min lagenge), β₁ = 9 (har extra 1 km pe 9 min add honge)

X = 2 km
ŷ = 8 + 9 × 2
= 26 minutes
X = 5 km
ŷ = 8 + 9 × 5
= 53 minutes
X = 0 km
ŷ = 8 + 9 × 0
= 8 min (= β₀!)
🤔 Ek model ne seekha: Salary = 15000 + 8000 × Experience_Years. Agar kisi ka experience 0 years hai, toh predicted salary kya hogi? Aur β₁ = 8000 ka kya matlab hai?
A₹8,000 — kyunki β₁ hi base salary hai
B₹15,000 — aur β₁ = 8000 matlab har ek saal ke experience pe ₹8,000 increase
C₹23,000 — β₀ aur β₁ add hote hain
DPredict nahi ho sakta — X=0 ka koi matlab nahi

Slope & Intercept — Kya Seekh Raha Hai Model?
INTERCEPT
β₀ = y-intercept
Jab X = 0 ho tab predicted y ki value.
Line y-axis ko kahan kaat ti hai.
SLOPE
β₁ = Δy / ΔX
X mein 1 unit change pe y mein kitna change.
Line ki steepness — positive ya negative.
Slope ke 3 Cases — Positive, Negative, Zero
β₁ > 0
Positive Slope
X badhta hai → y bhi badhta hai
Direct relationship. Line upar ki taraf jaati hai (left to right).
📚 Study hours ↑ → Exam score ↑
🏏 Practice ↑ → IPL runs ↑
β₁ < 0
Negative Slope
X badhta hai → y ghatta hai
Inverse relationship. Line neeche ki taraf jaati hai (left to right).
🏃 Age ↑ → Running speed ↓
❄️ AC usage ↑ → Temperature ↓
β₁ = 0
Zero Slope
X se y pe koi effect nahi
No relationship. Line horizontal hai — X feature useless hai prediction ke liye.
🎲 Shoe size aur exam score — koi relation nahi!
Python mein β₀ aur β₁ kaise dekhein?
🐍 Python
from sklearn.linear_model import LinearRegression
import numpy as np

# Distance (km) aur Delivery Time (min)
X = np.array([[1], [2], [3], [4], [5], [6], [7], [8]])
y = np.array([18, 26, 35, 43, 52, 60, 68, 77])

model = LinearRegression()
model.fit(X, y)

print(f"β₀ (Intercept): {model.intercept_:.2f}")  # ~9.8
print(f"β₁ (Slope):     {model.coef_[0]:.2f}")    # ~8.5

# Interpret karo:
# β₀ ≈ 10 → 0 km pe bhi ~10 min (restaurant prep)
# β₁ ≈ 8.5 → har 1 km extra = 8.5 min extra delivery time

# Manually predict karo:
dist = 3.5
predicted = model.intercept_ + model.coef_[0] * dist
print(f"\nManual: 3.5 km → {predicted:.1f} min")
print(f"sklearn: 3.5 km → {model.predict([[3.5]])[0]:.1f} min")
# Dono same answer denge!
β₀ ≈ 9.8 min (base prep time), β₁ ≈ 8.5 min/km. Manual calculation aur sklearn.predict() ka answer SAME hoga — kyunki internally wahi formula use hota hai: ŷ = β₀ + β₁ × X!

Cost Function — Model Kitna Galat Hai?
+30 XP on scroll
Core Idea — Ek Line Mein
Cost Function = ek measure jo batata hai ki model ki predictions actual values se kitni galat hain — jitna kam, utna better model.

Training ka goal = cost function ko minimize karna! Model best β₀ aur β₁ dhundhta hai jo cost ko sabse kam kare.
Step 1 — Residual (Error) Kya Hai?
Residual = Actual − Predicted
Har data point ke liye: eᵢ = yᵢ − ŷᵢ

Matlab: actual value aur model ki predicted value ka difference.
→ Positive residual = model ne under-predict kiya (actual > predicted)
→ Negative residual = model ne over-predict kiya (actual < predicted)
→ Zero residual = perfect prediction! (rarely happens)
RESIDUAL
eᵢ = yᵢ − ŷᵢ = yᵢ − (β₀ + β₁Xᵢ)
Har point ke liye actual aur predicted ka gap
Step 2 — SSE aur MSE: Total Error Measure
Seedha Sum Kyun Nahi Karte?
Agar seedha residuals add karein, positive aur negative cancel ho jaate hain — total error zero lag sakta hai!

Example: e₁ = +5, e₂ = −5 → sum = 0. But dono predictions galat hain!
Fix: Square karo pehle — squaring se negative bhi positive ho jaata hai!
SUM OF SQUARED ERRORS
SSE = Σ (yᵢ − ŷᵢ)²
Har point ka squared error add karo — sab n points ke liye
MEAN SQUARED ERROR — COST FUNCTION J(β)
J(β) = MSE = (1/n) × Σ (yᵢ − ŷᵢ)²
SSE ko n se divide karo → average error per point. Training ka goal: J(β) minimize karo!
ΣSigma — "sum karo" (sab n points ke liye)
yᵢi-th point ka actual value
ŷᵢi-th point ka predicted value (β₀ + β₁Xᵢ)
nTotal data points ki sankhya
J(β)Cost function — β ke function ke roop mein
Common Error Metrics
SSE = Σ(yᵢ−ŷᵢ)² → Total squared error (no average)

MSE = SSE/n → Average squared error per point

RMSE = √MSE → Same units as y (interpretable!)

MAE = (1/n) Σ|yᵢ−ŷᵢ| → Average absolute error (outlier robust)
MSE vs MAE — Kab Kya?
MSE use karo jab:
Outlier penalties zyada chahiye — squared error bade mistakes ko heavily penalize karta hai.

MAE use karo jab:
Outliers data mein hain aur unhe zyada weight nahi dena — absolute error more robust hota hai.
🤔 Model ne predict kiya: ŷ = [22, 35, 48]. Actual values hain: y = [25, 32, 50]. MSE kya hoga?
AMSE ≈ 0.67 — residuals ka simple average
BMSE = 22 — squared errors ka sum
CMSE ≈ 7.33 — squared errors ka average (SSE/n)
DMSE ≈ 2.71 — RMSE formula use kiya

Cost Function — "Bowl Shape" Intuition
Visual Intuition — Cost Function ka Shape
J(β) = MSE ek convex bowl shape banata hai jab β values pe plot karo.

→ Bowl ke kisi bhi point pe shuru karo → har baar slope (gradient) neeche bowl ki tarf point karta hai
→ Bowl ka sabse neeche wala point = minimum cost = best β values!

Yahi guarantee karta hai ki optimization hamesha global minimum find kar legi — koi local minimum trap nahi (MSE ke case mein)!
COST FUNCTION J(β) vs β₁
J(β) ↑
      │  *               *
      │    *           *
      │      *       *    ← galat β, high cost
      │        *   *
      │          *      ← minimum! best β here
      └────────────────────────→ β₁
Ye parabola (bowl) convex hai — ek hi global minimum hai → guaranteed best solution!
Training mein exactly kya hota hai?
Random β₀, β₁ se shuru karo
Initially koi bhi random values — e.g., β₀=0, β₁=0 (ya small random numbers). Cost zyada hogi.
Current cost calculate karo — J(β)
MSE nikalo current β values pe. Har training data point ke liye residuals calculate karo, square karo, average lo.
β update karo — cost kam karne ki direction mein
Bowl ke neeche ki direction mein step lo. OLS directly best β deta hai. Gradient Descent iteratively steps leta hai.
Repeat jab tak minimum cost na mile
Convergence tak repeat karo — jab β values change karna band kar dein, minimum mil gaya!

OLS — Best β₀ aur β₁ Directly Nikalna!
+30 XP on scroll
OLS Kya Hai?
Ordinary Least Squares (OLS) = ek mathematical method jo SSE ko minimize karne wale exact β values seedha calculate karta hai — koi iteration nahi, koi guessing nahi!

Ye calculus use karta hai — MSE ko β ke respect mein differentiate karo, zero set karo, aur solve karo. Result: closed-form formulas!
OLS Closed-Form Formulas
OLS SLOPE — β₁
β₁ = Σ(Xᵢ − X̄)(yᵢ − ȳ)  /  Σ(Xᵢ − X̄)²
Covariance(X, y) / Variance(X) — X aur y ek saath kitna vary karte hain vs X akele kitna vary karta hai
OLS INTERCEPT — β₀
β₀ = ȳ − β₁ × X̄
Pehle β₁ nikalo, phir β₀. Best fit line hamesha (X̄, ȳ) se guzarti hai!
X̄X ka mean (average of all X values)
ȳy ka mean (average of all y values)
Xᵢ − X̄Har X point ka mean se deviation
yᵢ − ȳHar y point ka mean se deviation
Σ(Xᵢ−X̄)²Sum of squared X deviations = Variance of X × n
Complete Mathematical Derivation — Step by Step
Step 0 — Model Notation (y = mx + c)
Notebooks mein m aur c notation use hota hai. Ye β₁ aur β₀ ke equivalent hain:
ŷ = mx + c    where    m = β₁ (slope)  |  c = β₀ (intercept)
Error (residual) for each point:   eᵢ = dᵢ = yᵢ − ŷᵢ  (actual minus predicted)
Step 1 — Define Total Error (SSE & MSE)
Total squared error across all n points:
E = d₁² + d₂² + d₃² + … + dₙ²  =  Σ dᵢ²
Expanding each squared residual:
E = Σ (yᵢ − ŷᵢ)²
MSE (Cost function J) — average over n points:
J(m, c) = MSE = (1/n) × Σᵢ (yᵢ − ŷᵢ)²  =  (1/n) × Σᵢ (yᵢ − mxᵢ − c)²
This is our Cost Function — we want to find m and c that minimize J(m, c).
Geometric View — Residuals on the Regression Line
Purple line = best-fit ŷ=mx+c. Red dots = actual data points yᵢ. Dashed lines = residuals dᵢ. OLS minimizes Σdᵢ².
Step 2 — Minimize J: Take Partial Derivatives & Set = 0
To find the minimum of J(m, c), take partial derivatives w.r.t. m and c separately, and set both to zero:

∂J/∂m = 0    →    find optimal slope m
∂J/∂c = 0    →    find optimal intercept c
Why both? J depends on TWO unknowns (m and c) — we need two equations to solve for both uniquely.
Step 3 — Solve ∂J/∂c = 0 → Intercept Formula
Differentiate J = (1/n) Σ (yᵢ − mxᵢ − c)² with respect to c:
∂J/∂c  =  (1/n) · Σ 2(yᵢ − mxᵢ − c)(−1)  =  0
Cancel (−2/n), we get:
Σ (yᵢ − mxᵢ − c)  =  0
Expand the sum (Σ distributes):
Σyᵢ − m·Σxᵢ − n·c  =  0
Divide everything by n (using x̄ = Σxᵢ/n, ȳ = Σyᵢ/n):
c  =  ȳ − m·x̄     ← Intercept formula (c = β₀)
Key insight: The best-fit line always passes through the mean point (x̄, ȳ)!
Step 4 — Solve ∂J/∂m = 0 → Slope Formula (Full Algebra)
Differentiate J w.r.t. m:
∂J/∂m  =  (1/n) · Σ 2(yᵢ − mxᵢ − c)(−xᵢ)  =  0
Cancel (−2/n), set to zero:
Σ xᵢ(yᵢ − mxᵢ − c)  =  0
Substitute c = ȳ − mx̄ from Step 3:
Σ xᵢ(yᵢ − mxᵢ − ȳ + mx̄)  =  0
Rearrange inside the bracket:
Σ xᵢ[(yᵢ − ȳ) − m(xᵢ − x̄)]  =  0
Expand the summation:
Σ xᵢ(yᵢ − ȳ) − m · Σ xᵢ(xᵢ − x̄)  =  0
Using the identity  Σ xᵢ(xᵢ−x̄) = Σ (xᵢ−x̄)²  and  Σ xᵢ(yᵢ−ȳ) = Σ (xᵢ−x̄)(yᵢ−ȳ):
Σ (xᵢ−x̄)(yᵢ−ȳ)  =  m · Σ (xᵢ−x̄)²
Solve for m:
m  =  Σ(xᵢ−x̄)(yᵢ−ȳ)  /  Σ(xᵢ−x̄)²     ← Slope formula (m = β₁)
Numerator = Covariance(x, y) × n  |  Denominator = Variance(x) × n
✅ Final OLS Solution — Derived from First Principles
SLOPE
m = Σ(xᵢ−x̄)(yᵢ−ȳ)
─────────────────
Σ(xᵢ−x̄)²
INTERCEPT
c = ȳ − m · x̄
Line passes through (x̄, ȳ)
Derivation summary: Set ∂J/∂c = 0 → c = ȳ − mx̄  |  Set ∂J/∂m = 0, substitute c → solve for m  |  Both equations together = Normal Equations
Cost Function J(m) — Parabolic Bowl Shape
Setting ∂J/∂m = 0 finds the exact bottom of the bowl — the optimal slope m*. The parabolic (convex) shape guarantees a unique global minimum.
Intuition — Formula Ka Matlab Kya Hai?
m (β₁) = Cov(x,y) / Var(x) ka matlab:

→ Numerator (Covariance): X aur y dono apne means se kitna ek saath move karte hain? Positive = ek saath badhte hain, Negative = ulta.
→ Denominator (Variance of X): X apne mean se kitna spread hai?
→ Ratio: "X ke ek unit change pe y mein kitna change" — yahi slope hai!

c (β₀) = ȳ − m·x̄ ka matlab: Best fit line hamesha mean point (x̄, ȳ) se guzarti hai — c is point se calculate hota hai!
🤔 OLS mein β₁ (slope) calculate karne ke liye kya formula use hota hai?
Aβ₁ = Σ(Xᵢ − X̄)(yᵢ − ȳ) / Σ(Xᵢ − X̄)²
Bβ₀ = ȳ − β₁ × X̄
Cβ₁ = Σ(yᵢ − ȳ)² / Σ(yᵢ − ŷᵢ)²
Dβ₁ = (1/n) Σ (yᵢ − ŷᵢ)

from sklearn.linear_model import LinearRegression

# IPL data — same 5 players
X = np.array([[2], [3], [4], [5], [6]])  # Practice hours
y = np.array([30, 40, 50, 60, 70])       # Runs scored

# sklearn OLS (internally same formula!)
model = LinearRegression()
model.fit(X, y)
print(f"sklearn β₀ (Intercept): {model.intercept_:.1f}")  # 10.0
print(f"sklearn β₁ (Slope):     {model.coef_[0]:.1f}")    # 10.0

# Manual OLS formula se verify karo
X_vals = X.flatten()
X_mean = X_vals.mean()   # 4.0
y_mean = y.mean()         # 50.0

denominator = np.sum((X_vals - X_mean) ** 2)              # 10
beta1 = numerator / denominator                            # 10.0
beta0 = y_mean - beta1 * X_mean                           # 10.0

print(f"Manual β₁: {beta1:.1f}")   # 10.0 ← Same!

pred = beta0 + beta1 * new_player_hours

Gradient Descent — Pahaad Se Neeche Utarna!
+30 XP on scroll
Core Analogy — Aankhein Band Karke Pahaad Se Utaro
Imagine karo tum ek pahaad pe khade ho — raat ka andhera hai, kuch dikh nahi raha. Tumhara goal sabse neeche valley (minimum) mein pahunchna hai.

Tum kya karoge? Har kadam pe neeche ki taraf ghoom jao aur ek step lo! Yahi Gradient Descent hai.

→ Pahaad = Cost Function J(β)
→ Tumhari position = current β values
→ Neeche ki direction = negative gradient (slope ki opposite direction)
→ Valley (bottom) = minimum cost = best β values!
Update Rule — Gradient Descent Formula
GRADIENT DESCENT UPDATE RULE
β₁ := β₁ − α × ∂J/∂β₁
Simultaneously β₀ bhi update hota hai: β₀ := β₀ − α × ∂J/∂β₀
:=Update karo (assign karo)
αLearning rate — kadam kitna bada? (alpha)
∂J/∂β₁Partial derivative — β₁ direction mein slope of cost
−Minus — gradient ke opposite direction mein jao!
Partial Derivatives — Expanded Form
Cost function J = (1/n)Σ(yᵢ − β₀ − β₁Xᵢ)² ko β₀ aur β₁ ke respect mein differentiate karte hain:

PARTIAL DERIVATIVE w.r.t. β₀
∂J/∂β₀ = (−2/n) × Σ(yᵢ − ŷᵢ)
= (−2/n) × sum of all residuals
PARTIAL DERIVATIVE w.r.t. β₁
∂J/∂β₁ = (−2/n) × Σ(yᵢ − ŷᵢ) × Xᵢ
= (−2/n) × sum of (residual × X) for all points
Learning Rate α — Bahut Important Hyperparameter!
🎯
α sahi ho (e.g., 0.01)
Smooth convergence — gradually bowl ke bottom pe pahunch jaata hai. Best scenario!
🏃
α bahut bada (e.g., 10)
Overshoot! Bowl ke ek taraf se dusri taraf jump karta hai — diverge ho jaata hai, minimum kabhi nahi milta!
🐢
α bahut chota (e.g., 0.00001)
Bahut slow — converge hoga but bahut time lagega. Thousands of iterations needed!

Gradient Descent — Scratch Se Implement Karo
Gradient Descent From Scratch — Har Step Clearly
🐍 Python — Gradient Descent From Scratch
import numpy as np

# ─── Inline Dataset: IPL — Practice Hours vs Runs ───
X = np.array([2, 3, 4, 5, 6], dtype=float)
y = np.array([30, 40, 50, 60, 70], dtype=float)
n = len(X)

# ════════════════════════════════════════
# Gradient Descent Setup
# ════════════════════════════════════════
beta0 = 0.0          # Intercept — random shuru karo
beta1 = 0.0          # Slope — random shuru karo
alpha = 0.01         # Learning rate — step size
iterations = 1000    # Kitni baar update karein

# Cost function — MSE
def compute_cost(X, y, b0, b1):
    y_pred = b0 + b1 * X
    residuals = y - y_pred
    return (1/len(y)) * np.sum(residuals**2)

print(f"Shuruat: β₀={beta0:.1f}, β₁={beta1:.1f}")
print(f"Initial Cost (MSE): {compute_cost(X,y,beta0,beta1):.2f}\n")

# ════════════════════════════════════════
# Gradient Descent Loop
# ════════════════════════════════════════
for i in range(iterations):
    y_pred  = beta0 + beta1 * X           # Current predictions
    residuals = y - y_pred                 # Errors (residuals)

    # Gradients (partial derivatives)
    grad_b0 = (-2/n) * np.sum(residuals)          # ∂J/∂β₀
    grad_b1 = (-2/n) * np.sum(residuals * X)      # ∂J/∂β₁

    # Update β — gradient ke opposite direction mein
    beta0 = beta0 - alpha * grad_b0
    beta1 = beta1 - alpha * grad_b1

    # Progress print karo (every 200 iterations)
    if i % 200 == 0:
        cost = compute_cost(X, y, beta0, beta1)
        print(f"Iter {i:4d}: β₀={beta0:.3f}, β₁={beta1:.3f}, Cost={cost:.4f}")

# ════════════════════════════════════════
# Final Result
# ════════════════════════════════════════
print(f"\n=== GRADIENT DESCENT RESULT ===")
print(f"β₀ (Intercept): {beta0:.4f}  (Expected: 10.0)")
print(f"β₁ (Slope):     {beta1:.4f}  (Expected: 10.0)")
print(f"Final Cost:     {compute_cost(X,y,beta0,beta1):.6f}")

# 7 hours prediction
pred = beta0 + beta1 * 7
print(f"\n7 hours practice → {pred:.1f} runs")

Level 5 · Boss Topic
R² Score — Model Kitna Accha Explain Karta Hai?
+30 XP on scroll
Core Idea — Ek Line Mein
R² (R-squared) = batata hai ki model y ki total variation ka kitna percent explain kar pa raha hai.

Range: 0 to 1 (kabhi kabhi negative bhi). 1 = perfect, 0 = model kuch explain nahi kar raha (sirf mean predict kar raha hai jitna hi).
R-SQUARED FORMULA
R² = 1 − (SSR / SST)
= 1 − [Σ(yᵢ−ŷᵢ)²] / [Σ(yᵢ−ȳ)²]
SSRSum of Squared Residuals = Σ(yᵢ−ŷᵢ)² — model ka remaining error
SSTTotal Sum of Squares = Σ(yᵢ−ȳ)² — total variation in y
SSR/SSTFraction of variation jo model explain NAHI kar paaya
1 − SSR/SSTFraction jo model ne explain KIYA = R²
R² Values — Kya Matlab Hai?
🏆
R² = 1.0
Perfect fit! Model har point exactly predict karta hai. SSR = 0. Real data mein almost impossible.
😊
R² = 0.85+
85%+ variation explained. Very good model! Most real-world good models 0.7–0.95 range mein hote hain.
😐
R² = 0.5
50% variation explain hua. Model kuch seekha hai lekin bahut unexplained hai. More features needed?
❌
R² = 0 ya <0
Model mean se bhi worse! (Negative R² possible when wrong model). Sirf mean predict karo toh R²=0.
R² Numbers ke Saath Samjho — HDFC Loan Example
HDFC loan EMI predict karne wala model: SST = 1,000,000 (total variation in EMI), SSR = 150,000 (model ke baad remaining error)

R² = 1 − (150,000 / 1,000,000) = 1 − 0.15 = 0.85

Matlab: Model 85% variation explain karta hai EMI mein! 15% still unexplained (shayad credit score, employment type missing hai dataset se).
RMSE = √(SSR/n) se actual rupees mein error samajh sakte ho!
R² Calculate karo — Manual aur sklearn dono
🐍 Python — R² Manual + sklearn
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score, mean_squared_error

# IPL dataset — same as before
X = np.array([[2],[3],[4],[5],[6]])
y = np.array([30, 40, 50, 60, 70])

model = LinearRegression()
model.fit(X, y)
y_pred = model.predict(X)

# ─── Manual R² calculation ───
y_mean  = y.mean()                       # ȳ = 50

SSR = np.sum((y - y_pred) ** 2)          # Σ(yᵢ − ŷᵢ)² — residual sum
SST = np.sum((y - y_mean) ** 2)          # Σ(yᵢ − ȳ)²  — total sum
R2_manual = 1 - (SSR / SST)

print(f"SST (Total variation):     {SST:.2f}")
print(f"SSR (Residual / Error):    {SSR:.6f}")
print(f"\nR² Manual:   {R2_manual:.6f}")

# ─── sklearn r2_score ───
R2_sklearn = r2_score(y, y_pred)
print(f"R² sklearn:  {R2_sklearn:.6f}")
# Dono same hain!

# ─── Other metrics ───
mse  = mean_squared_error(y, y_pred)
rmse = np.sqrt(mse)
print(f"\nMSE:         {mse:.6f}")
print(f"RMSE:        {rmse:.6f} runs")
print(f"\nInterpretation:")
print(f"  R² ≈ {R2_sklearn:.0%} — Model ne {R2_sklearn:.0%} variation explain kiya!")
print(f"  RMSE ≈ {rmse:.2f} runs — Average prediction error")
SST = 200.00, SSR ≈ 0.000000. R² Manual ≈ 1.000000, R² sklearn ≈ 1.000000. Perfect fit! (Kyunki ye perfectly linear synthetic data tha). RMSE ≈ 0.000 runs. Real noisy data mein R² thoda less hoga — 0.85–0.95 range good hai!

🐍 Python — Pizza Example
import numpy as np
from sklearn.linear_model import LinearRegression

# Training data — Pizza size vs Price
X_train = np.array([[8], [10], [12], [15]])   # Size in inches
y_train = np.array([280, 450, 675, 1200])     # Price in ₹

# OLS Linear Regression
model = LinearRegression()
model.fit(X_train, y_train)

m = model.coef_[0]          # Slope
c = model.intercept_         # Intercept

print(f"Slope (m):     {m:.2f}")   # ~132.10
print(f"Intercept (c): {c:.2f}")   # ~-834.88
print(f"\nEquation: Price = {c:.2f} + {m:.2f} × Size")

# Predict new pizza sizes
new_sizes = np.array([[17], [18], [20], [22], [26]])
predictions = model.predict(new_sizes)

print("\nPredictions:")
for size, price in zip(new_sizes.flatten(), predictions):
    print(f"  {size} inch → ₹{price:.2f}")

Final Summary — Linear Regression Math at a Glance
ConceptFormulaMatlab (Intuition)
L1 Line Equation ŷ = β₀ + β₁X Model ki prediction — intercept + slope × input
L1 Slope & Intercept β₁ = Δy/ΔX, β₀ = ŷ when X=0 β₁ = rate of change, β₀ = base value
L2 Residual eᵢ = yᵢ − ŷᵢ Actual minus predicted — prediction error
L2 Cost Function (MSE) J = (1/n)Σ(yᵢ−ŷᵢ)² Average squared error — minimize karo training mein!
L3 OLS — β₁ β₁ = Σ(Xᵢ−X̄)(yᵢ−ȳ) / Σ(Xᵢ−X̄)² Cov(X,y) / Var(X) — direct exact formula
L3 OLS — β₀ β₀ = ȳ − β₁X̄ Line always passes through mean point (X̄, ȳ)
L4 Gradient Descent β := β − α × ∂J/∂β Pahaad se neeche utaro — iterative optimization
L5 R² Score R² = 1 − SSR/SST Explained variation / Total variation — 1.0 = perfect
