AdaBoost in Supervised LearningAdaBoost in Supervised Learning

AdaBoost = Adaptive Boosting. Labeled training examples par weak classifiers sequentially train hote hain. Har round current learner ki mistakes ke according sample importance update hoti hai, aur final prediction learner-weighted votes combine karti hai.

Non-technical example: targeted revision
Teacher first practice round mein student mistakes dekhta hai. Next round hard examples ko more attention deta hai. Different rounds ke decisions combine hote hain. Analogy adaptive focus explain karti hai—algorithm labels change nahi karta; training sample weights update karta hai.

Supervised

Inputs X aur known target labels y needed hain. Mistakes actual labels ke against measured hoti hain.

Boosting

Later learners earlier round ke weighted errors se influenced hote hain; independent bagging fits jaisa workflow nahi.

This lesson focuses on AdaBoost classification. AdaBoostRegressor exists, but uses a different regression-specific procedure; classifier formulas directly apply mat karo.

QuestionHinglish answer
What?Sequential ensemble of weighted weak classifiers.
Why?Simple learners combine karke more expressive predictor banane aur difficult examples par focus karne ke liye.

Weak Learner, Stump & Two Kinds of WeightAdaBoost in Supervised Learning

Decision stump depth-1 tree hai: normally one split and up to two leaves. Ek feature-based question se limited decisions leta hai. AdaBoost multiple such learners combine karke richer boundary learn kar sakta hai.

ConceptWhat it controlsDo not confuse with
Sample weight wᵢTraining row ka current influenceFeature values or target label
Estimator weight αₜFinal ensemble mein learner t ka contributionIndividual row weight
Learning rate ηEach round contribution/update strengthNumber of examples
n_estimatorsMaximum boosting roundsGuaranteed fitted count
“Weak” ka meaning intentionally useless nahi. Binary discrete boosting mein current weighted distribution par useful learner ko error below 0.5 chahiye. Ordinary accuracy intuition multiclass ke liye directly apply nahi hoti.

Higher sample weight row learner ke weighted fitting objective ko more influence karti hai. Scikit-learn's default stump supports sample weights directly; bootstrap resampling compulsory step nahi.

Repeat adaptively

Combine α-weighted predictions
  1. Start with normalized weights, usually 1/n per row.
  2. Fit one weak classifier using current sample weights.
  3. Compute weighted classification error.
  4. Assign learner contribution based on that error and learning rate.
  5. Increase relative importance of current mistakes; normalize weights.
  6. Train next learner, then combine accepted learners for prediction.

Weighted Error & Update FormulasAdaBoost in Supervised Learning

This lesson uses the discrete SAMME convention, with K classes and positive learning rate η. Current sample weights are normalized.

εt=∑i=1nwt,i𝟙(ht(xi)≠yi)
αt=η[ln(1−εtεt)+ln(K−1)]
w~t+1,i=wt,ieαt𝟙(ht(xi)≠yi)

Then divide all updated weights by their sum. Mistakes multiply by exp(α); correct rows retain unnormalized weights. After normalization, correct-row weights generally shrink and wrong-row relative weights grow.

Binary K=2: valid finite positive-contribution round needs 0<ε<0.5. ε=0 is a perfect round: handle separately/stop, not divide by zero. Error at or above random threshold 1−1/K is not a useful SAMME learner; implementation handles stopping/rejection.
Why do other tutorials show ½ ln((1−ε)/ε)?

Classic binary AdaBoost often uses half-sized α and symmetric update exp(−α·y·h), with y,h in {−1,+1}. Binary SAMME uses doubled α with mistakes-only exp(α) update. With corresponding definitions, normalized sample-weight trajectories and binary vote decisions agree. Do not mix one convention's α with the other update rule.

Worked Round: Five Rows, One MistakeAdaBoost in Supervised Learning

Five rows start with weight 0.2 each. Learner misclassifies only row E. Binary K=2, learning rate η=1:

  1. Weighted error ε = weight(E) = 0.2.
  2. α = ln(0.8/0.2) = ln(4) ≈ 1.3863.
  3. Correct rows stay 0.2 before normalization; E becomes 0.2×4=0.8.
  4. Total = 4×0.2 + 0.8 = 1.6.
  5. Normalize: correct rows each 0.125; E becomes 0.5.

BCorrect0.200.200.125

EWrong0.200.800.500
Next learner ko E correctly classify karna more important ho gaya, but algorithm guarantees nahi karta ki E next round correct hoga. New learner can make different errors.

Later rounds error sum of current wrong-row weights hai, raw “number wrong / number rows” only when weights equal. One high-weight mistake multiple low-weight mistakes se more costly ho sakti hai.

Python: Verify, Tune & EvaluateAdaBoost in Supervised Learning

Dependencies: pip install scikit-learn numpy. Run the three blocks in order. Code uses modern estimator= and omits legacy algorithm arguments.

Python • 1. Verify the worked binary update
import numpy as np

weights = np.full(5, 0.2)
wrong = np.array([False, False, False, False, True])
error = weights[wrong].sum()
learning_rate = 1.0
assert 0 < error < 0.5

alpha = learning_rate * np.log((1 - error) / error)
updated = weights * np.exp(alpha * wrong)
updated /= updated.sum()

print("Weighted error:", error)
print("SAMME binary alpha:", alpha)
print("Next weights:", updated)
assert np.allclose(updated, [0.125, 0.125, 0.125, 0.125, 0.5])
Python • 2. Train-only hyperparameter search
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split, StratifiedKFold, GridSearchCV
from sklearn.ensemble import AdaBoostClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline

X, y = make_moons(n_samples=400, noise=0.28, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, stratify=y, random_state=42
)
pipeline = Pipeline([
    ("impute", SimpleImputer(strategy="median")),
    ("ada", AdaBoostClassifier(
        estimator=DecisionTreeClassifier(max_depth=1),
        random_state=42,
    )),
])
search = GridSearchCV(
    pipeline,
    param_grid={
        "ada__n_estimators": [50, 100],
        "ada__learning_rate": [0.3, 1.0],
        "ada__estimator__max_depth": [1, 2],
    },
    scoring="f1_macro",
    cv=StratifiedKFold(n_splits=4, shuffle=True, random_state=42),
    refit=True,
    n_jobs=1,
    error_score="raise",
)
search.fit(X_train, y_train)
best = search.best_estimator_
print("Selected parameters:", search.best_params_)
print("Best mean CV macro F1:", search.best_score_)

ada = best.named_steps["ada"]
rounds = len(ada.estimators_)
print("Actual fitted rounds:", rounds)
print("First learner errors:", ada.estimator_errors_[:min(5, rounds)])
print("First learner weights:", ada.estimator_weights_[:min(5, rounds)])

Synthetic two-feature binary dataset needs no download. Missing-value imputer included to demonstrate fold-safe preprocessing; generated data has no missing values. Tree base learners generally scaling require nahi karte. Eight candidates × four folds = 32 candidate-fold fits, plus selected-model refit.

Python • 3. Final test and trusted export
from sklearn.metrics import classification_report, confusion_matrix, roc_auc_score
import pickle

# No test results were used for hyperparameter selection.
predictions = best.predict(X_test)
probabilities = best.predict_proba(X_test)
print("Class column order:", best.named_steps["ada"].classes_)
print(confusion_matrix(y_test, predictions))
print(classification_report(y_test, predictions, zero_division=0))

# This binary dataset's labels are 0 and 1.
positive_column = int(np.flatnonzero(
    best.named_steps["ada"].classes_ == 1
)[0])
print("ROC-AUC:", roc_auc_score(y_test, probabilities[:, positive_column]))

artifact = {"pipeline": best, "feature_names": ["feature_0", "feature_1"]}
with open("adaboost_pipeline.pkl", "wb") as file:
    pickle.dump(artifact, file)

# Load only the trusted artifact from this workflow.
with open("adaboost_pipeline.pkl", "rb") as file:
    restored = pickle.load(file)
assert np.array_equal(predictions, restored["pipeline"].predict(X_test))
assert np.allclose(probabilities, restored["pipeline"].predict_proba(X_test))
print("Export/load parity passed.")
Scores illustrative hain, guaranteed improvement nahi. Real task par single-tree and other baselines training-only CV se compare karo. Final test score dekhkar settings change mat karo. Probabilities calibrated confidence hona guaranteed nahi.
Pickle untrusted source se load mat karo. Deployment mein complete fitted Pipeline, feature schema and matching dependency versions preserve karo. Training reference information stored in model components sensitive ho sakti hai.

Parameters, Multiclass & Practical LimitsAdaBoost in Supervised Learning

Setting / behaviorWhat to know
n_estimatorsMaximum rounds; perfect-fit/other stopping conditions se fewer fits possible.
learning_ratePositive contribution multiplier; estimator count ke saath tune karo.
estimatorMust support sample_weight and classification attributes; default is depth-1 tree.
Tree max_depthStump vs deeper learner complexity trade-off.
random_stateControls seeds for stochastic base-estimator behavior.
Multiclass SAMMELearner weight includes ln(K−1); useful-error threshold is below 1−1/K.
Outliers / wrong labelsRepeated errors large weights attract kar sakti hain; data quality matters.

Lower learning rate often more rounds demand karta hai, but best trade-off validation se choose karo. More rounds or deeper learners automatically better nahi; noise/label issues overfocus ho sakte hain.

AdaBoost usually sequential dependency ki wajah se independent rounds parallelize nahi karta. Cross-validation candidates/folds parallelize kar sakte hain within compute limits. staged_predict/staged_score diagnostics ke liye useful; stage selection validation data se karo, final test curves se nahi.

Legacy tutorials may show base_estimator, algorithm="SAMME.R" or different coefficient conventions. Installed version ki documentation follow karo. This code targets modern discrete AdaBoostClassifier API.

AdaBoost vs Bagging & Other EnsemblesAdaBoost in Supervised Learning

AspectAdaBoostBagging
Training orderSequential, adaptiveIndependent base fits
Data emphasisUpdated sample weightsBootstrap sampling
Final classificationLearner-weighted decisionsAverage probabilities when available; otherwise voting
Common base treesShallow trees / stumpsOften high-variance deeper trees
SensitivityMay focus heavily on noise/mislabeled rowsOften stabilizes variance; noise still matters

Random Forest bagged trees mein split-wise feature randomness add karta hai. Voting uses separately specified fixed aggregation rule. Stacking OOF predictions se meta-model learns. AdaBoost learns learner contributions along a sequential weighted-training path.

One-Minute Revision

AdaBoost = Adaptive Boosting. Sample weights ≠ learner weights. Weighted error drives contribution. Wrong rows gain relative attention after normalization. Prediction uses weighted learners, not unweighted majority. Binary and multiclass formulas/thresholds differ. Validate cleanly; labels and feature values are not rewritten.
