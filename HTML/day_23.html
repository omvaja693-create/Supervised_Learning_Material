Project Overview: Model se App takClassification Deployment

Is project mein flower measurements se Iris species classify karenge: setosa, versicolor ya virginica. Training script Pipeline fit karega, artifact export karega, aur Streamlit app us artifact se new inputs predict karega. Browser ke har rerun par model retrain nahi hoga.

Non-technical analogy: complete recipe kit
Sirf final cooking instruction bhejna enough nahi agar ingredients ka preprocessing bhi important hai. Pipeline ek complete recipe kit jaisa hai: missing-value handling, scaling aur classifier ek saath travel karte hain. Deployment mein raw measurements enter karo; trained recipe internally apply hoti hai.

Learning outcome

Classification workflow, leakage-safe preprocessing, trusted pickle export, consistent inference aur cloud deployment ka connection.

Scope

Single-row prediction educational demo. Production monitoring, access control, fairness aur dataset representativeness separate engineering requirements hain.

Yeh tutorial deployment-ready code explain karta hai. GitHub/Community Cloud steps learner ko apne account par complete karne hain; live cloud deployment is file mein automatically nahi hua hai.

Complete train.py: Fit, Evaluate, ExportClassification Deployment

Fresh project directory mein train.py ka complete code below hai. Installation aur execution commands Section 9 mein diye hain. Training 80% partition mein hoti hai; remaining 20% independent test set hai.

Python • train.py
from pathlib import Path
from importlib.metadata import version
import json
import pickle
import platform

import numpy as np
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split, StratifiedKFold, GridSearchCV
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, f1_score

BASE = Path(__file__).resolve().parent
data = load_iris(as_frame=True)
X, y = data.data, data.target
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, stratify=y, random_state=42
)

pipeline = Pipeline([
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", StandardScaler()),
    ("classifier", LogisticRegression(max_iter=2000)),
])
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
search = GridSearchCV(
    pipeline, {"classifier__C": [0.1, 1.0, 10.0]},
    scoring="f1_macro", cv=cv, refit=True, n_jobs=1,
    error_score="raise",
)
search.fit(X_train, y_train)
fitted = search.best_estimator_
pred = fitted.predict(X_test)
print("Best parameters:", search.best_params_)
print(classification_report(y_test, pred, zero_division=0))

packages = ["streamlit", "scikit-learn", "numpy", "pandas", "scipy"]
artifact = {
    "pipeline": fitted,
    "feature_names": list(X.columns),
    "class_names": list(data.target_names),
    "defaults": X_train.median().to_dict(),
    "training_min": X_train.min().to_dict(),
    "training_max": X_train.max().to_dict(),
    "versions": {name: version(name) for name in packages},
    "python": platform.python_version(),
}
model_path = BASE / "iris_pipeline.pkl"
with model_path.open("wb") as file:
    pickle.dump(artifact, file, protocol=pickle.HIGHEST_PROTOCOL)

# Trusted local round-trip: outputs must remain unchanged.
with model_path.open("rb") as file:
    restored = pickle.load(file)
assert np.array_equal(pred, restored["pipeline"].predict(X_test))
assert np.allclose(
    fitted.predict_proba(X_test),
    restored["pipeline"].predict_proba(X_test),
)
(BASE / "requirements.txt").write_text(
    "\n".join(f"{name}=={version(name)}" for name in packages) + "\n",
    encoding="utf-8",
)
(BASE / "metrics.json").write_text(json.dumps({
    "best_params": search.best_params_,
    "cv_macro_f1": search.best_score_,
    "test_macro_f1": f1_score(y_test, pred, average="macro"),
    "python": artifact["python"],
}, indent=2), encoding="utf-8")
print("Export, prediction parity, and dependency pins complete.")

What gets saved?

Fitted pipeline ke saath feature names, class names, training-only UI defaults, observed ranges aur package versions bhi save hote hain. metrics.json evaluation summary rakhta hai, while requirements.txt exact runtime package versions record karta hai.

Class names numeric target labels 0, 1, 2 ke corresponding hain for Iris. Other datasets mein explicit label mapping create karo; model.classes_ probability-column order use karo. Test score dekhkar parameter grid change mat karo.

Pickle / .bin & Prediction ParityClassification Deployment

pickle.dump() Python object ko binary bytes mein serialize karta hai. .pkl, .pickle ya .bin sirf filename extensions hain. Agar pickle se file write hui hai, matching load method pickle.load() hoga.

SaveLoadMeaning
open(path, 'wb')open(path, 'rb')Binary write / read modes
pickle.dump(artifact, file)pickle.load(file)Serialize / deserialize
Full Pipeline savedRaw features passed to PipelineNo separate manual scaling
Versions pinnedMatching Python and packagesReduce incompatibility risk
Never load untrusted pickle: Deserialization arbitrary code execute kar sakta hai. User-uploaded model pickle loading feature mat add karo. Version checks or a file hash pickle ko inherently safe nahi banate. Repository/artifact source trusted hona chahiye before loading.

Training code export ke baad same held-out inputs ke labels aur probabilities compare karta hai. Yeh prediction parity test confirm karta hai ki saved pipeline reload ke baad same behavior retain kar raha hai.

Scikit-learn cross-version model loading supported assumption nahi hai. Same training/runtime dependencies use karo; incompatible environment ho toh correct pinned environment mein retrain/re-export karo. Python major/minor bhi align karo.

.bin extension use karna ho toh?

Training aur app dono mein iris_pipeline.pkl ko iris_pipeline.bin rename karo. Filename change se serialization format ya security characteristics nahi badalte.

Complete app.py: Streamlit InterfaceClassification Deployment

App ek trusted local artifact load karta hai, form ke through inputs collect karta hai aur inference display karta hai. User ko model upload karne ka option nahi diya gaya.

Python • app.py
from pathlib import Path
from importlib.metadata import version
import pickle
import platform

import numpy as np
import pandas as pd
import streamlit as st

BASE = Path(__file__).resolve().parent
MODEL_PATH = BASE / "iris_pipeline.pkl"
st.set_page_config(page_title="Iris Classifier", page_icon="🌸", layout="centered")

@st.cache_resource
def load_artifact(path, modified_ns):
    # Only load the artifact built and reviewed by this project.
    # modified_ns is a cache key: replacing the file triggers reload.
    with Path(path).open("rb") as file:
        artifact = pickle.load(file)
    for name, trained_version in artifact["versions"].items():
        if version(name) != trained_version:
            raise ValueError(f"Version mismatch for {name}. Use requirements.txt.")
    trained_python = artifact["python"].split(".")[:2]
    if platform.python_version().split(".")[:2] != trained_python:
        raise ValueError("Use the same Python major/minor as training.")
    if list(artifact["pipeline"].feature_names_in_) != artifact["feature_names"]:
        raise ValueError("Artifact feature schema is inconsistent.")
    return artifact

st.title("Iris Classifier")
st.caption("Flower measurements in cm")
try:
    artifact = load_artifact(str(MODEL_PATH), MODEL_PATH.stat().st_mtime_ns)
except Exception:
    st.error("Model unavailable. Check the trusted artifact and training environment.")
    st.stop()

features = artifact["feature_names"]
with st.form("measurements"):
    values = {}
    cols = st.columns(2)
    for i, feature in enumerate(features):
        with cols[i % 2]:
            values[feature] = st.number_input(
                feature, min_value=0.01,
                value=float(artifact["defaults"][feature]), step=0.1,
            )
    submitted = st.form_submit_button("Classify flower")

if submitted:
    row = pd.DataFrame([values], columns=features)
    if not np.isfinite(row.to_numpy()).all():
        st.error("All measurements must be finite numbers.")
        st.stop()

    outside = [
        name for name in features
        if values[name] < artifact["training_min"][name]
        or values[name] > artifact["training_max"][name]
    ]
    if outside:
        st.warning("Outside observed training range: " + ", ".join(outside))

    model = artifact["pipeline"]
    label = int(model.predict(row)[0])
    probabilities = model.predict_proba(row)[0]
    names = [artifact["class_names"][int(c)] for c in model.classes_]
    st.success("Predicted species: " + artifact["class_names"][label])
    st.dataframe(pd.DataFrame({
        "Species": names,
        "Model probability": probabilities,
    }), hide_index=True)
    st.bar_chart(pd.Series(probabilities, index=names, name="Probability"))
    st.caption("Educational demo. Probabilities are not a guarantee of correctness.")

Important app behavior

st.form input changes batch karta hai; submit par classification hoti hai. st.cache_resource model load across reruns cache karta hai. File modification timestamp argument included hai, so changed artifact new cache key generate karega.

Cached model global resource ho sakta hai; requests ke beech ise fit() ya mutate mat karo. Input range warning strict scientific guarantee nahi; observed training min/max ke outside sample extrapolation risk signal karta hai.

Probability bars model estimates hain, guaranteed real-world confidence nahi. Highest probability predicted class batata hai, lekin calibration, distribution shift aur wrong units predictions affect kar sakte hain.

Inference Contract Lab

Conceptual contract checker only; no Python model runs inside this HTML page.

Local smoke-test checklist

Start with 5.1, 3.5, 1.4, 0.2 cm and confirm result appears. Change inputs, submit again, inspect probabilities. Verify probabilities sum approximately to 1, labels align with class columns, and missing artifact produces a clean error rather than a blank page.

Delete/rebuild artifact only intentionally; never silently train a new model from the serving app. Reloaded model must match the training schema.

Deploy on Streamlit Community CloudClassification Deployment

  1. Local app test karo; generated iris_pipeline.pkl aur requirements.txt present hon.
  2. GitHub repository mein app.py, train.py, trusted artifact, requirements aur optional metrics summary include karo. Dataset built-in hai, CSV needed nahi.
  3. Virtual environment, caches aur secrets commit mat karo. Repository access aur visibility intentionally choose karo.
  4. Streamlit Community Cloud mein sign in karke Create app choose karo.
  5. Repository, branch aur entrypoint app.py select karo. Nested project folder ho toh complete relative path use karo.
  6. Advanced settings mein training-compatible Python version choose karo. That version unavailable ho toh supported version mein locally retrain and regenerate dependency pins/artifact.
  7. Deploy run karo; build logs mein dependency installation aur startup errors inspect karo.
  8. Cloud app par same local example test karo. Outputs local trusted model se consistent hon; app link then share karo.

Reproducible deployment

Generated package pins same environment se come karte hain jahan model train hua. Target Python version ke liye pinned wheels available hona bhi important hai; pins alone OS/Python incompatibility solve nahi karte. Clean environment mein python -m pip install -r requirements.txt karke test karo.

Path(__file__).resolve().parent artifact path script location se build karta hai, local working-directory assumptions se nahi. Filename casing exact rakho; cloud Linux case-sensitive ho sakta hai.
