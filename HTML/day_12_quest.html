Decision Tree — Ek Line Mein
Decision Tree Regression = ek model jo data ko binary splits (if/else rules) se divide karta hai — jab tak har leaf node mein similar target values na aa jayein, aur phir leaf ka mean = prediction!

Bilkul ek doctor ki tarah: "Kya age > 40? Kya BP > 130? Kya BMI > 30?" → ek diagnosis. Tree har sawaal ka ek branch hai!
🌳 Decision Tree — Mumbai House Price Predictor (Simplified)
🌱
Root Node
Tree ka pehla node. Sabse important feature pe best split karta hai. Ek tree mein sirf 1 root hota hai.
🔀
Internal Node
Beech mein aane wale nodes. Ek feature pe split karte hain, 2 children produce karte hain. Left/Right branches.
🍃
Leaf Node
Tree ka end point. Koi aur split nahi. Prediction = mean(y) in that leaf. Regression mein average value.
📏
Split
Ek condition: "Feature ≤ threshold?" → left branch. "> threshold?" → right branch. Binary decisions at each node.
DT Regression vs DT Classification — Key Difference
Decision Tree Regression
→ Target: continuous (price, temperature, salary)
→ Leaf prediction: mean(y values in leaf)
→ Split criteria: MSE reduction (variance)
→ Error metric: RMSE, MAE, R²
Decision Tree Classification
→ Target: discrete (0/1, cat/dog, fraud/legit)
→ Leaf prediction: majority class in leaf
→ Split criteria: Gini / Entropy (impurity)
→ Error metric: Accuracy, F1, ROC-AUC

Mathematical Formulation — Best Split Kaise Milta Hai?
+30 XP on scroll
The Core Question — Algorithm kya decide karta hai?
Har node pe algorithm ye decide karta hai:
1. Kaunsa feature pe split karein? (Area? Bedrooms? Distance?)
2. Kaunsa threshold use karein? (Area ≤ 800? ≤ 1000? ≤ 1500?)

Answer: Jo split Residual Sum of Squares (RSS) / MSE sabse zyada reduce kare!
Splitting Criterion — MSE / Variance Reduction
MSE SPLIT CRITERION
MSE(split) = (n_L/n) × MSE_L + (n_R/n) × MSE_R
MSE_L = Var(y) in Left child  |  MSE_R = Var(y) in Right child
Find feature j aur threshold t that minimizes MSE(split)
LEAF MSE (INDIVIDUAL NODE)
MSE_node = (1/n) × Σᵢ₌₁ⁿ (yᵢ − ȳ)²
ȳ = mean(y) in the node  |  yᵢ = each target value  |  n = samples in node
Also written as Var(y) — same as variance of target values in node
n_L, n_RSamples in left and right child
nTotal samples in current node (n_L + n_R)
MSE_L, MSE_RMean Squared Error in left/right child
ȳMean target value in the node
ReductionMSE_parent − MSE(split) → maximize this!
CART Algorithm — How Best Split is Found
Start at Root — All Data in One Node
All n training samples ek root node mein. Node MSE = Var(y_all) calculate karo — ye parent MSE hai.
Example: [42, 45, 55, 85, 68, 50] → ȳ = 57.5, MSE_parent = 243.6
Try Every Feature, Every Threshold
Har feature ke sorted unique values try karo as thresholds. Har (feature, threshold) pair ke liye:
→ Left child = samples where Xⱼ ≤ t → compute MSE_L
→ Right child = samples where Xⱼ > t → compute MSE_R
→ Weighted MSE = (n_L/n)×MSE_L + (n_R/n)×MSE_R
Best Split = Minimum Weighted MSE
Jo (feature j*, threshold t*) sabse kam weighted MSE deta hai → BEST SPLIT!
MSE Reduction (aka Variance Reduction or Information Gain for Regression):
Reduction = MSE_parent − [(n_L/n)×MSE_L + (n_R/n)×MSE_R]
Recursively Split Children
Left aur Right child nodes ko bhi same process se best split dhundho.
Recursion tab ruke jab: min_samples_leaf reached, max_depth hit, ya MSE improvement negligible
Leaf Prediction = Mean of Samples
Har leaf node ka prediction = ȳ_leaf = mean(y values in leaf)
Prediction for new x: traverse the tree → reach a leaf → return ȳ_leaf
Numerical Example — Best Split Find Karna
4 houses ke saath: Area=[800, 900, 1200, 1500], Price=[42, 50, 75, 85]

Parent node: ȳ = (42+50+75+85)/4 = 63. MSE_parent = [(42-63)² + (50-63)² + (75-63)² + (85-63)²]/4 = [441 + 169 + 144 + 484]/4 = 309.5

Try split: Area ≤ 1000
Left (800,900): ȳ_L = 46, MSE_L = [(42-46)² + (50-46)²]/2 = [16+16]/2 = 16
Right (1200,1500): ȳ_R = 80, MSE_R = [(75-80)² + (85-80)²]/2 = [25+25]/2 = 25
Weighted MSE = (2/4)×16 + (2/4)×25 = 8 + 12.5 = 20.5
MSE Reduction = 309.5 − 20.5 = 289.0 ← huge improvement!

Tree Anatomy — Key Terms
Depth = root se leaf tak ki maximum distance. Depth=0 at root.
Node MSE / Impurity = variance of y values in that node. Lower = purer node.
Samples = number of training points reaching that node.
Value = predicted output for samples in that node (mean of y).
Feature Importance = total MSE reduction contributed by a feature across all splits.
max_depth = hyperparameter that limits tree depth (prevents overfitting).

Approach 1 — From Scratch (CART Algorithm)
🐍 python — decision tree regression from scratch 
class DTRNode:
    """A node in the Decision Tree."""
    def __init__(self, feature=None, threshold=None,
                 left=None, right=None, value=None):
        self.feature   = feature    # feature index for split
        self.threshold = threshold  # split threshold value
        self.left      = left       # left child node
        self.right     = right      # right child node
        self.value     = value      # leaf prediction (mean of y)


class DecisionTreeRegressorScratch:
    def __init__(self, max_depth=3, min_samples_leaf=1):
        self.max_depth       = max_depth
        self.min_samples_leaf = min_samples_leaf
        self.root            = None

    def _mse(self, y):
        """Calculate MSE (variance) of target values."""
        if len(y) == 0: return 0
        return np.var(y)    # = Σ(yᵢ - ȳ)² / n

    def _best_split(self, X, y):
        """Find best (feature, threshold) pair using CART algorithm."""
        n_samples, n_features = X.shape
        best_mse = float('inf')
        best_feature, best_threshold = None, None

        for feature_idx in range(n_features):
            # Try all unique values as thresholds
            thresholds = np.unique(X[:, feature_idx])
            for threshold in thresholds:
                left_mask  = X[:, feature_idx] <= threshold
                right_mask = ~left_mask

                if left_mask.sum() < self.min_samples_leaf: continue
                if right_mask.sum() < self.min_samples_leaf: continue

                y_left, y_right = y[left_mask], y[right_mask]
                n_L, n_R = len(y_left), len(y_right)

                # Weighted MSE of this split
                weighted_mse = (n_L/n_samples)*self._mse(y_left) + \
                               (n_R/n_samples)*self._mse(y_right)

                if weighted_mse < best_mse:
                    best_mse       = weighted_mse
                    best_feature   = feature_idx
                    best_threshold = threshold

        return best_feature, best_threshold

    def _build_tree(self, X, y, depth=0):
        """Recursively build the tree using CART."""
        # Stopping conditions → create leaf node
        if depth >= self.max_depth or len(y) <= self.min_samples_leaf:
            return DTRNode(value=np.mean(y))   # Leaf: predict mean!

        # Find best split
        feature, threshold = self._best_split(X, y)
        if feature is None:
            return DTRNode(value=np.mean(y))

        # Split data
        left_mask  = X[:, feature] <= threshold
        right_mask = ~left_mask

        # Recurse on children
        left_subtree  = self._build_tree(X[left_mask], y[left_mask], depth+1)
        right_subtree = self._build_tree(X[right_mask], y[right_mask], depth+1)

        return DTRNode(feature=feature, threshold=threshold,
                       left=left_subtree, right=right_subtree)

    def fit(self, X, y):
        self.root = self._build_tree(X, y)
        return self

    def _predict_sample(self, x, node):
        """Traverse tree for one sample."""
        if node.value is not None:     # Leaf node
            return node.value
        if x[node.feature] <= node.threshold:
            return self._predict_sample(x, node.left)
        return self._predict_sample(x, node.right)

    def predict(self, X):
        return np.array([self._predict_sample(x, self.root) for x in X])

Hyperparameters & Pruning — Overfitting Control!
+30 XP on scroll
The Overfitting Problem
Unconstrained Decision Tree = 100% training accuracy kyunki har sample ek alag leaf mein hota hai. Ye pure memorization hai, generalization nahi!

Solution: Regularization via Hyperparameters — tree ki growth limit karo → bias thoda badhao → variance bahut kam karo → better generalization!
Key Hyperparameters — Kya Control Karta Hai?
ParameterDefaultEffectIncrease → Effect
max_depth None (unlimited) Max depth of tree ↑ Complexity → Overfitting risk ↑
min_samples_split 2 Min samples needed to split a node ↑ Less splits → Simpler tree → Less overfitting
min_samples_leaf 1 Min samples in any leaf node ↑ Each leaf covers more data → Smoother predictions
max_features None (all) Features considered at each split ↓ Randomness ↑ → Can reduce overfitting (like RF)
max_leaf_nodes None Max number of leaf nodes ↓ Limit → Simpler tree → Better generalization
ccp_alpha 0.0 Cost Complexity Pruning parameter ↑ More pruning → Simpler tree → Less overfitting
📊 max_depth vs Performance — The Sweet Spot
Training error keeps dropping. Test error: first drops (less underfitting), then rises (more overfitting). Sweet spot = min test error depth!
Cost-Complexity Pruning (CCP) — Post-Pruning
COST-COMPLEXITY PRUNING
R_α(T) = R(T) + α × |T|
R(T) = total MSE of tree T  |  |T| = number of leaf nodes  |  α (ccp_alpha) = complexity penalty
Prune subtrees that don't significantly reduce error. Larger α → more pruning → simpler tree.

    cv_r2 = cross_val_score(model, X, y, cv=5, scoring='r2').mean()
    cv_r2_per_alpha.append(cv_r2)

# Step 3: Best alpha
best_alpha = ccp_alphas[np.argmax(cv_r2_per_alpha)]
print(f"Best ccp_alpha: {best_alpha:.4f}")
print(f"Best CV R²:     {max(cv_r2_per_alpha):.4f}")

# Step 4: Final model with best alpha
final_model = DecisionTreeRegressor(ccp_alpha=best_alpha, random_state=42)
final_model.fit(X_train, y_train)
print(f"\n🌳 Pruned Tree — depth={final_model.get_depth()}, "
      f"leaves={final_model.get_n_leaves()}")
print(f"   Test R²: {final_model.score(X_test, y_test):.4f}")

Final Summary — Decision Tree Regression Cheatsheet
📐 ALL KEY CONCEPTS AT A GLANCE
LEAF PREDICTION
ŷ = mean(y values in leaf)
Every sample reaching same leaf gets same prediction
SPLIT CRITERION (MSE)
Weighted MSE = (n_L/n)MSE_L + (n_R/n)MSE_R
Minimize this → best split. CART algorithm tries all features × thresholds
MSE REDUCTION
Reduction = MSE_parent − Weighted MSE
Feature Importance = total reduction contributed by each feature
PRUNING (CCP)
R_α(T) = R(T) + α × |T|
Higher ccp_alpha → more pruning → simpler tree → less overfitting

Final Message
Decision Tree Regression = ek interpretable, powerful algorithm — agar/toh rules se continuous predictions karta hai!
→ Intuition: Data ko binary splits se divide karo. Leaf = mean(y) of samples reaching it. Simple aur explainable!
→ Math (CART): Every feature × threshold try karo, minimum weighted MSE split choose karo recursively.
→ Overfit warning: Unconstrained tree = memorization! max_depth, min_samples_leaf, CCP se control karo!
→ Strengths: No scaling needed, handles non-linear patterns, interpretable rules, feature importance free!

Decision Trees ek simple model hain lekin powerful ensemble methods (Random Forest, XGBoost) ka foundation hain. Root se leaf tak ka safar samajh liya toh advanced ML easy lagega! 🌳🎯🚀
