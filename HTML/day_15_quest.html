Section 01Overview

Streamlit Kya Hai?

Streamlit Python ka open-source framework hai jisse data science aur machine learning apps quickly build kiye ja sakte hain. Aap Python statements likhte ho, aur Streamlit unhe browser mein headings, tables, charts, inputs, buttons aur outputs ke form mein render karta hai.

Is tutorial mein hum ek simple regression model ko web app banayenge. User features enter karega, app saved model ko load karegi, aur predicted value screen par show hogi.

Core IdeaStreamlit app ka main file normal Python script hota hai. Run command: streamlit run app.py.
PythonWidgetsML AppDeployment
🧾 Non-Technical Example

Calculator app mein user numbers enter karta hai, button press karta hai, aur answer dekhta hai. Streamlit isi idea ko ML tak le jaata hai: user features enter karta hai aur trained model prediction return karta hai.

Section 025 W's Framework

What?

Python-based framework jo data/ML applications ko interactive browser UI mein convert karta hai.

Why?

Frontend JavaScript ke bina model demo, dashboard, prototype, aur internal tool quickly banane ke liye.

When?

Jab trained model ko users, teammates, clients, ya reviewers ke liye accessible banana ho.

How?

`st.title`, `st.number_input`, `st.button`, `st.metric`, `st.write` jaise APIs se.

Where?

Local machine, Streamlit Community Cloud, Docker/server, ya internal hosting par.

Who?

Data scientists, ML learners, analysts, and developers jo Python-first app banana chahte hain.

Section 08Deploy on Streamlit Community Cloud

Deployment Checklist

  1. Project ko GitHub repository mein push karo.
  2. `app.py`, model artifact, aur `requirements.txt` commit karo.
  3. Dependencies mein compatible versions pin karo, e.g. `streamlit`, `pandas`, `scikit-learn`, `joblib`.
  4. Streamlit Community Cloud mein repository, branch, aur entrypoint select karo.
  5. Deploy ke baad logs, model path, and input behavior check karo.
Portable pathsLocal absolute path jaise `/Users/.../model.pkl` mat use karo. `Path(__file__).parent / "model.pkl"` relative path deployment mein safer hai.
SecretsAPI keys ya passwords code/repository mein commit mat karo. Secret management feature use karo; public app mein private model/data ka access carefully design karo.
LocalDeployment concernBetter practice
Works on my machineVersion differencesrequirements.txt pin karo
Local model pathCloud path missingRelative path use karo
Large artifactRepo size / startup slowRegistry or object storage consider karo

Section 09Python Implementation

app.py
from pathlib import Path import joblib import pandas as pd import streamlit as st st.set_page_config(page_title="House Price Predictor", page_icon="🏠") st.title("🏠 House Price Predictor") st.caption("Streamlit + exported regression Pipeline") @st.cache_resource def load_model(): model_path = Path(__file__).parent / "house_price_pipeline.pkl" return joblib.load(model_path) model = load_model() area = st.number_input("Area (sq ft)", min_value=100, value=1200) bedrooms = st.number_input("Bedrooms", min_value=1, max_value=10, value=3, step=1) age = st.number_input("Property age (years)", min_value=0, value=5) location = st.selectbox("Location", ["North", "South", "East", "West"]) if st.button("Predict Price"): row = pd.DataFrame([{ "area_sqft": area, "bedrooms": bedrooms, "age_years": age, "location": location }]) prediction = model.predict(row)[0] st.success(f"Estimated price: ₹{prediction:,.0f}")
Run locally: streamlit run app.py The browser opens a local interactive regression app.
requirements.txt
streamlit pandas scikit-learn joblib
Tip: deployment consistency ke liye tested versions pin kar sakte ho, for example streamlit==1.x.x.
Small but importantTraining ke time model mein `location` categories supported honi chahiye. `OneHotEncoder(handle_unknown="ignore")` unseen category par app ko crash hone se help karta hai, but data quality still validate karni chahiye.

Section 10Common Mistakes

Model har rerun par load karna⌄

Har widget interaction par script rerun hoti hai. `st.cache_resource` se model loading repeat nahi hoti aur app responsive rehti hai.

Input columns ka order/name mismatch⌄

Model training schema ko exactly follow karo. DataFrame with named columns use karna positional arrays se safer hota hai.

requirements.txt bhool jana⌄

Cloud ko dependencies pata nahi chalengi. Required packages aur compatible versions declare karo.

Secret ya absolute path commit karna⌄

Secrets ko repository mein mat rakho. Model file ke liye relative path use karo so that local and cloud environments work consistently.
