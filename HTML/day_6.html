MLR — Ek Line, Bahut Saare Features!

SLR se MLR — Extension Ka Idea
Simple Linear Regression (SLR):   ŷ = β₀ + β₁X  → sirf ek feature
Multiple Linear Regression (MLR):   ŷ = β₀ + β₁X₁ + β₂X₂ + … + βₙXₙ  → n features ek saath!

Real world mein ek house ki price sirf size se decide nahi hoti — location, bedrooms, age, floor, distance from metro sab matter karta hai. MLR ye sab ek model mein handle karta hai!
MLR MODEL EQUATION
ŷ = β₀ + β₁X₁ + β₂X₂ + β₃X₃ + … + βₙXₙ
Population form:   y = β₀ + β₁X₁ + … + βₙXₙ + ε   |   ε ~ N(0, σ²)
ŷPredicted output (y-hat)
β₀Intercept — sab X=0 hone par ŷ ki value
β₁…βₙCoefficients — har feature ka "weight"
X₁…XₙIndependent features (input variables)
εError term — jo explain nahi ho saka
nNumber of features (predictors)
📈 Simple Linear Regression
ŷ = β₀ + β₁ × Size
1 feature → 2D plane mein ek line
📊 Multiple Linear Regression
ŷ = β₀ + β₁×Size + β₂×Rooms + β₃×Age
n features → n+1 dimensional hyperplane
🇮🇳 Real India Example — Mumbai House Price Prediction
Features: Size (sqft) = X₁, Bedrooms = X₂, Distance from Metro (km) = X₃, Age of Building (years) = X₄

Price (₹L) = 20 + 0.05×Size − 2.5×Distance + 3.2×Bedrooms − 0.8×Age
Coefficients ka matlab:
→ β₁ = 0.05: 1 sqft zyada = ₹5K price up (size held constant)
→ β₂ = −2.5: 1 km dur = ₹2.5L price down (distance penalty)
→ β₃ = 3.2: 1 extra bedroom = ₹3.2L up
→ β₄ = −0.8: 1 year old = ₹80K price down
Prediction example:
→ 1000 sqft, 3 bed, 1 km metro, 5 years old:
→ ŷ = 20 + (0.05×1000) − (2.5×1) + (3.2×3) − (0.8×5)
→ ŷ = 20 + 50 − 2.5 + 9.6 − 4
→ ŷ = ₹73.1 Lakhs

Partial Coefficient
Har βᵢ = "Y mein change jab Xᵢ 1 unit badhta hai aur baaki sab features constant rehte hain." Ye partial effect hai!
📐
Hyperplane
SLR mein line, MLR mein hyperplane. 2 features = 3D plane. n features = (n+1) dimensional hyperplane in feature space.
⚖️
Ceteris Paribus
Latin: "All else equal." MLR ke coefficients ye guarantee dete hain — ek feature ka effect isolate kiya jaa sakta hai.

Step 2 — Normal Equation — Closed Form OLS for MLR
NORMAL EQUATION — OLS FOR MLR
β̂ = (XᵀX)⁻¹ Xᵀy
Best coefficients jo SSE = (y − Xβ)ᵀ(y − Xβ) minimize karte hain — directly, analytically!
XᵀTranspose of design matrix X
XᵀX(n+1)×(n+1) square matrix
(XᵀX)⁻¹Inverse of XᵀX (exists when X is full rank)
Xᵀy(n+1)×1 cross-product vector
β̂Estimated coefficients vector
SSE ko matrix form mein likho
SSE = Σ(yᵢ − ŷᵢ)² = (y − Xβ)ᵀ(y − Xβ)
= yᵀy − 2βᵀXᵀy + βᵀXᵀXβ  (expand karo)
β ke respect mein differentiate karo → zero set karo
∂SSE/∂β = −2Xᵀy + 2XᵀXβ = 0
→  XᵀXβ = Xᵀy   ← Normal Equations
β ke liye solve karo
(XᵀX) invertible hai (full rank data assumed) → dono sides pe (XᵀX)⁻¹ multiply karo:
β̂ = (XᵀX)⁻¹ Xᵀy ✅
Connection to SLR — Special Case
Jab n=1 (sirf ek feature), Normal Equation SLR ke OLS formulas ke identical results deta hai:
β₁ = Σ(Xᵢ−X̄)(yᵢ−ȳ)/Σ(Xᵢ−X̄)²  aur  β₀ = ȳ − β₁X̄  — same answer, matrix form ka special case!
Normal Equation — Advantages
✅ Closed-form: Direct exact solution — no iterations
✅ No hyperparameters: Learning rate set nahi karna
✅ Guaranteed global optimum (convex loss)
✅ Small-medium datasets (m ≤ 10K rows) ke liye fast
Normal Equation — Limitations
❌ Large datasets pe slow: (XᵀX)⁻¹ = O(n³) operations — very expensive for large n
❌ Singular matrix: Multicollinearity hone par (XᵀX) invertible nahi hoti
❌ Memory intensive: XᵀX = (n+1)×(n+1) — large feature sets pe memory issue
→ Large data pe Gradient Descent prefer karo!
🤔 MLR ka Normal Equation β̂ = (XᵀX)⁻¹Xᵀy hai. Agar data mein 2 features perfectly correlated hain (X₂ = 2X₁), toh kya problem hogi?
AModel ki prediction accuracy improve hogi — zyada features = better
BXᵀX singular (non-invertible) ho jaayegi — Normal Equation fail
CModel training bahut slow ho jaayegi — computational issue
Dβ values automatically zero ho jaayengi — no issue

MLR Assumptions — Model Reliable Kab Hota Hai?
+30 XP on scroll
Assumptions Kyun Zaroori Hain?
MLR model tabhi valid predictions aur reliable coefficients deta hai jab kuch mathematical conditions data mein satisfy hoti hain. Ye assumptions violate hone par — coefficients biased ya inefficient ho jaate hain, confidence intervals galat hote hain, aur predictions unreliable.
🔗 Linearity — Linear Relationship
Assumption: y aur har Xᵢ ke beech linear relationship honi chahiye — ŷ = β₀ + β₁X₁ + … + βₙXₙ.
Check: Residual vs Fitted values plot — koi pattern nahi hona chahiye. Scatter plots each feature vs y.
Fix if violated: Polynomial features add karo (X², log(X)), ya non-linear model use karo.
🔀 Independence — No Autocorrelation
Assumption: Observations ek doosre se independent hain — error εᵢ ka εⱼ se koi correlation nahi.
Check: Durbin-Watson test (value ≈ 2 = no autocorrelation). Time series data mein ye commonly violate hoti hai.
Fix if violated: Lagged variables add karo, ARIMA ya time-series models use karo.
📊 Homoscedasticity — Equal Error Variance
Assumption: Errors ki variance constant honi chahiye — Var(εᵢ) = σ² for all i. "Equal spread of residuals."
Check: Residual vs Fitted plot mein funnel shape nahi hona chahiye. Breusch-Pagan test.
Fix if violated (Heteroscedasticity): Log(y) transform, Weighted Least Squares, robust standard errors.
🔔 Normality of Errors
Assumption: Errors normally distributed honi chahiye: ε ~ N(0, σ²). Mainly inference (p-values, CI) ke liye zaroori.
Check: Q-Q plot of residuals — points diagonal line pe hone chahiye. Shapiro-Wilk test.
Fix if violated: Log/Box-Cox transform target variable. Large samples mein CLT se ye automatically better hoti hai.
🚫 No Multicollinearity — Features Independent
Assumption: Independent variables ke beech high correlation nahi honi chahiye. VIF (Variance Inflation Factor) check karo.
VIF > 10 = serious problem. VIF > 5 = concern.
Fix: Correlated features mein se ek drop karo, PCA use karo, Ridge/Lasso regularization try karo.
📌 No Perfect Multicollinearity — Full Rank X
Assumption: Design matrix X full column rank honi chahiye — koi bhi feature doosre ka perfect linear combination nahi hona chahiye.
Example: Agar X₃ = 2×X₁ + X₂ exactly, toh XᵀX singular ho jaayegi → Normal Equation fail.
Fix: Perfectly correlated feature drop karo — always before training.
Residual Plots — Assumptions ke Diagnostic
Random scatter — no pattern. Assumptions OK!
Funnel/fan shape = Heteroscedasticity. Log transform try karo.
U-shape = non-linearity. Polynomial features add karo.
🤔 Ek MLR model mein tumhare paas features hain: Income (₹), Age, aur Monthly_Spending = 0.4×Income + 0.2×Age (exactly). Ye scenario kaunsa problem create karega aur kya hoga?
ANormality assumption violate hogi — Q-Q plot check karo
BAutocorrelation problem hogi — Durbin-Watson test fail karega
CHeteroscedasticity hogi — residual vs fitted plot mein funnel shape
DPerfect Multicollinearity — XᵀX singular, Normal Equation fail, coefficients undefined

Approach 1 — Normal Equation: From Scratch (NumPy)
🐍 python — normal equation from scratch 
def mlr_normal_equation(X, y):
    """
    MLR using Normal Equation: β̂ = (XᵀX)⁻¹ Xᵀy
    
    Steps:
    1. Design matrix banao (bias column add karo)
    2. XᵀX calculate karo
    3. Inverse nikalo
    4. Xᵀy calculate karo
    5. β̂ = (XᵀX)⁻¹ Xᵀy
    """
    m = X.shape[0]   # number of data points
    
    # Step 1: Design matrix — first column = all 1s (intercept ke liye)
    ones = np.ones((m, 1))
    X_design = np.hstack([ones, X])       # shape: (m, n+1)
    print(f"Design matrix shape: {X_design.shape}")
    
    # Step 2: XᵀX — square matrix (n+1) × (n+1)
    XtX = X_design.T @ X_design
    print(f"XᵀX shape: {XtX.shape}")
    
    # Step 3: (XᵀX)⁻¹ — matrix inverse
    XtX_inv = np.linalg.inv(XtX)
    
    # Step 4: Xᵀy — cross product vector
    Xty = X_design.T @ y
    
    # Step 5: β̂ = (XᵀX)⁻¹ Xᵀy
    beta = XtX_inv @ Xty
    
    return beta

# ── Run Normal Equation ──────────────────────────────────────
beta_hat = mlr_normal_equation(X, y)

feature_names = ['β₀ (Intercept)', 'β₁ (Area)', 'β₂ (Bedrooms)',
                 'β₃ (Distance)', 'β₄ (Age)']

print("\n📐 Estimated Coefficients (Normal Equation):")
print("-" * 45)
for name, val in zip(feature_names, beta_hat):
    print(f"  {name:20s} = {val:8.4f}")

# ── Predictions using our β̂ ──────────────────────────────────
ones = np.ones((X.shape[0], 1))
X_design = np.hstack([ones, X])
y_pred_scratch = X_design @ beta_hat

print("\n📊 Actual vs Predicted (₹ Lakhs):")
for act, pred in zip(y, y_pred_scratch):
    print(f"  Actual: {act:6.1f}  →  Predicted: {pred:6.2f}  |  Error: {act-pred:+.2f}")

Multicollinearity & VIF — Ye Hidden Enemy!
+30 XP on scroll
Multicollinearity kya hai?
Multicollinearity = jab two ya more independent features highly correlated hain — matlab ek feature ki information doosre mein already captured hai.

Problem: Model ko samajh nahi aata ki kaunsa feature y ko actually drive kar raha hai → coefficients unreliable, standard errors inflate, p-values mislead karte hain. Model prediction theek ho sakti hai lekin interpretation galat hoti hai!
VIF — Variance Inflation Factor
VIF FORMULA
VIF(Xⱼ) = 1 / (1 − Rⱼ²)
Rⱼ² = R² jab Xⱼ ko doosre saare features (X₁…Xₙ, j≠ⱼ) se regress karo. High Rⱼ² = Xⱼ ki info doosron mein hai = high VIF = multicollinearity!
VIF = 1No collinearity — perfect
VIF 1–5Acceptable — low collinearity
VIF 5–10Moderate — investigate
VIF > 10Serious multicollinearity — fix karo!
VIF = ∞Perfect collinearity — model fail
📊 VIF Scale — Interpretation Guide
VIF = 1.2 (Area)✅ No collinearity
VIF = 3.4 (Bedrooms)⚠️ Low — acceptable
VIF = 6.8 (Floor_Area)⚠️ Moderate — investigate
VIF = 14.2 (Total_Area)❌ Serious — fix!
VIF Calculation — Python Code
🐍 python — VIF & multicollinearity detection 
import pandas as pd
import numpy as np
from statsmodels.stats.outliers_influence import variance_inflation_factor

# ── VIF Calculation Function ──────────────────────────────────
def calculate_vif(df, features):
    """
    VIF calculate karo har feature ke liye.
    VIF(Xⱼ) = 1 / (1 - Rⱼ²)
    Jahan Rⱼ² = R² when Xⱼ regressed on all other features
    """
    X = df[features].values
    vif_data = []
    
    for i, feat in enumerate(features):
        vif = variance_inflation_factor(X, i)
        vif_data.append({'Feature': feat, 'VIF': round(vif, 2)})
    
    vif_df = pd.DataFrame(vif_data).sort_values('VIF', ascending=False)
    return vif_df

# ── Problematic Dataset — house mein correlated features ──────
# Floor_Area ≈ Area (highly correlated!)
data_mc = pd.DataFrame({
    'Area':       [800, 1000, 1200, 1500, 1800, 900,  1100, 1350],
    'Bedrooms':   [2,   2,    3,    3,    4,    2,    3,    3   ],
    'Floor_Area': [810, 995,  1185, 1510, 1795, 905,  1095, 1360],  # ≈ Area!
    'Distance':   [2.0, 1.0,  1.0,  3.0,  0.5, 2.5,  1.5,  2.0 ],
})

features = ['Area', 'Bedrooms', 'Floor_Area', 'Distance']

print("📊 VIF Results BEFORE fixing multicollinearity:")
vif_before = calculate_vif(data_mc, features)
print(vif_before.to_string(index=False))

# ── Fix: Drop the correlated feature ─────────────────────────
features_fixed = ['Area', 'Bedrooms', 'Distance']

print("\n📊 VIF Results AFTER dropping Floor_Area:")
vif_after = calculate_vif(data_mc, features_fixed)
print(vif_after.to_string(index=False))

# ── Correlation Matrix — another check ───────────────────────
print("\n📊 Correlation Matrix:")
print(data_mc[features].corr().round(3))

Final Summary — MLR Math & Code at a Glance
📐 ALL KEY FORMULAS AT A GLANCE
MODEL EQUATION
ŷ = β₀ + β₁X₁ + β₂X₂ + … + βₙXₙ
Matrix: y = Xβ + ε
NORMAL EQUATION (OLS)
β̂ = (XᵀX)⁻¹ Xᵀy
Minimizes SSE = (y − Xβ)ᵀ(y − Xβ)
VIF — MULTICOLLINEARITY
VIF(Xⱼ) = 1 / (1 − Rⱼ²)
VIF > 10 = fix needed. VIF = 1 = perfect.
sklearn IN 3 LINES
model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
