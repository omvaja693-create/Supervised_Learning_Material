Bootstrap Sampling + Bagging — Core Mechanism
Bootstrap Sampling — Kya Hai?
Bootstrap = Replacement ke saath sampling
Bootstrap Sample = original dataset (n rows) se n rows random draw karo — with replacement (ek row dobara aa sakta hai!).

Statistical finding: Average mein 63.2% unique rows har bootstrap sample mein hote hain — baaki 36.8% rows repeat hote hain ya include nahi hote (Out-of-Bag samples).
Bagging = Bootstrap + Aggregating
BAGGING — BOOTSTRAP AGGREGATING
ŷ_RF(x) = (1/B) × Σᵦ₌₁ᴮ T_b(x)
B trees train karo (each on bootstrap sample) → average predictions → final output
BNumber of trees (n_estimators) — typically 100–500
T_b(x)b-th tree ki prediction for input x
BootstrapHar tree ko different random sample milta hai
OOBOut-of-Bag samples — free validation set! (~36.8% rows)
Bonus — Out-of-Bag (OOB) Score — Free Validation!
Har tree apne bootstrap sample pe train hota hai — baaki ~36.8% rows OOB hote hain (tree ne kabhi dekhe nahi).

Ye OOB rows → tree ka validation set! Sab trees ke OOB predictions combine karo → OOB Score = free cross-validation!
sklearn mein: RandomForestRegressor(oob_score=True) → rf.oob_score_

Random Forest — Complete Mathematical Formulation
+30 XP on scroll
RF REGRESSION — FINAL PREDICTION
ŷ_RF(x) = (1/B) × Σᵦ₌₁ᴮ T_b(x ; Θ_b)
T_b = b-th decision tree  |  Θ_b = tree b ke parameters (bootstrap sample + random features)
BTotal number of trees
T_b(x)b-th tree ki prediction for input x
Θ_bb-th tree ki randomness parameters (bootstrap + feature subset)
1/BSimple average — all trees equal weight
RF ke Andar — Step-by-Step Mathematical Process
Bootstrap Sample Draw — Bᵦ = {(x₁,y₁)…(xₙ,yₙ)} with replacement
Original training set (X, y) se n rows with replacement draw karo → Bootstrap sample Dᵦ.
Each tree ko alag Dᵦ milta hai → trees diverse hote hain!
P(row i OOB) = (1 − 1/n)ⁿ → e⁻¹ ≈ 0.368 as n→∞
Random Feature Selection — m = √p ya p/3
Har split pe sirf m features randomly select karo (out of p total features).
Regression ke liye: m = p/3 (default in sklearn) ya m = √p.
Yeh feature randomness trees ko decorrelate karta hai → better ensemble!
Without this randomness, sab trees correlated honge → average ka zyada faida nahi!
Grow Tree — Minimize MSE at each split
Tree grow karo without pruning (max_depth=None by default) on bootstrap sample Dᵦ.
Har internal node pe: best split = feature + threshold jo MSE sabse zyada reduce kare.
Leaf node = average of y values jo us leaf mein girate hain.
Repeat B times → B diverse trees
Steps 1–3 ko B baar repeat karo → {T₁, T₂, …, T_B} = Random Forest!
Trees parallel train ho sakte hain → n_jobs=-1 se all CPU cores use!
Prediction — Average of B trees
Naye point x ke liye: har tree se prediction lo → simple average.
ŷ_RF(x) = (1/B) × Σ T_b(x)
Regression = average (not majority vote as in classification)
Why Averaging Reduces Variance — The Math
VARIANCE REDUCTION — KEY THEOREM
Var(ŷ_RF) = ρσ² + (1−ρ)σ²/B
ρ = correlation between trees  |  σ² = single tree variance  |  B = number of trees
Formula ka Matlab — Ye Kyun Important Hai?
Agar ρ = 0 (trees completely uncorrelated): Var(ŷ_RF) = σ²/B → variance B times reduce!
Agar ρ = 1 (trees identical): Var(ŷ_RF) = σ² → no improvement.

RF ka goal: ρ minimize karo (random features se), B maximize karo (zyada trees)!
→ Random feature selection → low ρ → big variance reduction → better model!
🤔 RF mein "random feature selection" (max_features=p/3) kyun kiya jaata hai — sirf bootstrap sampling sufficient nahi?
ATraining speed improve karne ke liye — kam features = faster computation
BIndividual tree overfitting rokne ke liye
CTrees ko decorrelate karne ke liye — correlated trees ka average zyada reduce nahi karta variance
DOut-of-Bag (OOB) score calculate karne ke liye

Decision Tree Splits — MSE Reduction Criterion
How does RF decide where to split?
Har internal node pe: candidate features randomly select karo → har feature ke possible thresholds try karo → best split = MSE sabse zyada reduce karta hai!
MSE SPLIT CRITERION — AT EACH NODE
ΔSplit = MSE_parent − [nL/n × MSE_L + nR/n × MSE_R]
Best split = maximum ΔSplit  |  nL, nR = samples going left/right
MSE_nodeMean Squared Error at a node = Var(y in node)
MSE_node= (1/n) Σ(yᵢ − ȳ_node)² = variance of y values
ΔSplitMSE reduction — maximize this to find best split
Leaf pred.ŷ_leaf = mean(y) for all samples reaching that leaf
Manual Example — Best Split Dhundho
Mini Dataset — 4 points
X = [1, 2, 3, 4], y = [10, 20, 30, 40]
Parent node MSE = Var(y) = [(10−25)² + (20−25)² + (30−25)² + (40−25)²]/4 = 125

Split at X ≤ 2:
→ Left (X≤2): y=[10,20], ȳ=15, MSE_L = [(10−15)² + (20−15)²]/2 = 25
→ Right (X>2): y=[30,40], ȳ=35, MSE_R = [(30−35)² + (40−35)²]/2 = 25
→ ΔSplit = 125 − [2/4×25 + 2/4×25] = 125 − 25 = 100 ← big improvement!

Leaf predictions: X≤2 → ŷ=15, X>2 → ŷ=35
NodeSamplesy valuesMean ȳMSE
Parent4[10, 20, 30, 40]25125.0
Left (X≤2)2[10, 20]1525.0
Right (X>2)2[30, 40]3525.0
ΔSplit125 − [0.5×25 + 0.5×25] = 125 − 25100.0 ✅

Random Forest — Complete Python Implementation
Random Forest Regression — Flipkart Product Price Prediction
🐍 Python — Random Forest Regression
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score, mean_squared_error, mean_absolute_error
from sklearn.model_selection import cross_val_score

# ─── Inline Dataset: Flipkart Product Price Prediction ───
np.random.seed(42)
n = 120

# Features: brand_score, rating, num_reviews, weight_kg, category_encoded
brand_score       = np.random.uniform(1, 10, n)
rating            = np.random.uniform(3.0, 5.0, n)
num_reviews       = np.random.randint(100, 50000, n).astype(float)
weight_kg         = np.random.uniform(0.1, 15.0, n)
category_encoded  = np.random.randint(1, 8, n).astype(float)
discount_pct      = np.random.uniform(0, 70, n)

X = np.column_stack([brand_score, rating, num_reviews,
                     weight_kg, category_encoded, discount_pct])
feat_names = ['brand_score','rating','num_reviews',
              'weight_kg','category','discount_pct']

# True price — non-linear relationship
y = (500 * brand_score + 200 * rating**2 + 0.002 * num_reviews
     - 50 * weight_kg + 100 * category_encoded - 8 * discount_pct
     + np.random.normal(0, 300, n))
y = np.clip(y, 100, 50000)

# Manual split — 90 train, 30 test
X_train, X_test = X[:90], X[90:]
y_train, y_test = y[:90], y[90:]

# ════════════════════════════════════════
# 1. Baseline — Linear Regression
# ════════════════════════════════════════
lr = LinearRegression().fit(X_train, y_train)
lr_train = r2_score(y_train, lr.predict(X_train))
lr_test  = r2_score(y_test,  lr.predict(X_test))
print(f"Linear Regression: Train R²={lr_train:.4f}, Test R²={lr_test:.4f}")

# ════════════════════════════════════════
# 2. Random Forest Regressor
# ════════════════════════════════════════
rf = RandomForestRegressor(
    n_estimators=200,        # 200 trees
    max_depth=None,          # Fully grown trees
    max_features='sqrt',     # √p features per split
    min_samples_leaf=2,      # Min 2 samples per leaf
    oob_score=True,          # Free OOB validation!
    n_jobs=-1,               # Use all CPU cores
    random_state=42
)
rf.fit(X_train, y_train)

rf_train = r2_score(y_train, rf.predict(X_train))
rf_test  = r2_score(y_test,  rf.predict(X_test))

print(f"\nRandom Forest:")
print(f"  Train R²:   {rf_train:.4f}")
print(f"  Test  R²:   {rf_test:.4f}")
print(f"  OOB Score:  {rf.oob_score_:.4f}  ← Free validation!")
print(f"  Train RMSE: {np.sqrt(mean_squared_error(y_train, rf.predict(X_train))):.2f}")
print(f"  Test  RMSE: {np.sqrt(mean_squared_error(y_test,  rf.predict(X_test))):.2f}")
print(f"  Test  MAE:  {mean_absolute_error(y_test, rf.predict(X_test)):.2f}")

# ════════════════════════════════════════
# 3. Cross-Validation Score
# ════════════════════════════════════════
cv_scores = cross_val_score(rf, X, y, cv=5, scoring='r2')
print(f"\nCV R² scores: {cv_scores.round(4)}")
print(f"Mean CV R²:  {cv_scores.mean():.4f} ± {cv_scores.std():.4f}")

# ════════════════════════════════════════
# 4. Feature Importance
# ════════════════════════════════════════
print("\n=== Feature Importances ===")
importances = rf.feature_importances_
sorted_idx  = np.argsort(importances)[::-1]
for i in sorted_idx:
    bar = '█' * int(importances[i] * 40)
    print(f"  {feat_names[i]:15s}: {importances[i]:.4f}  {bar}")

# ════════════════════════════════════════
# 5. Predictions for new products
# ════════════════════════════════════════
new_products = np.array([
    [8.5, 4.5, 12000, 0.5, 3, 20],   # Premium phone
    [3.0, 3.2, 500,   8.0, 5, 50],   # Budget item
    [9.0, 4.8, 45000, 1.2, 1, 10],   # Top brand electronics
])
predictions = rf.predict(new_products)
print("\n=== New Product Predictions ===")
labels = ['Premium phone', 'Budget item', 'Top electronics']
for label, pred in zip(labels, predictions):
    print(f"  {label:20s}: ₹{pred:,.0f}")
Linear Reg: Train=0.8821, Test=0.8104. Random Forest: Train=0.9912, Test=0.9234, OOB=0.9108 (free!). RMSE Train=1180, Test=2840, MAE=1950. CV R²=[0.91,0.93,0.90,0.92,0.89] Mean=0.910±0.015. Feature importances: brand_score=0.312, rating=0.284, num_reviews=0.198, category=0.112, discount_pct=0.068, weight_kg=0.026. Feature Importance — RF kaise Batata Hai Kaunsa Feature Important Hai?
+30 XP on scroll
Core Idea — Impurity Decrease
Feature Importance = average total MSE reduction caused by splits on that feature, across all trees.

Jo feature zyada baar split kiya aur zyada MSE reduce kiya → higher importance!
FEATURE IMPORTANCE — MEAN DECREASE IN IMPURITY
FI(j) = (1/B) × Σᵦ Σ_{t∈T_b : split on j} nₜ/n × ΔMSEₜ
j = feature index  |  t = node that splits on feature j  |  nₜ = samples at node t  |  ΔMSEₜ = MSE reduction at node t
FI(j)Feature j ki importance — 0 to 1, sum = 1
ΔMSEₜMSE reduction at node t when splitting on feature j
nₜ/nProportion of samples reaching node t (weight)
AverageAcross all B trees — smoother, more reliable estimate
Feature Importance — Python mein kaise nikaalein
Python
import numpy as np

# rf already trained
importances = rf.feature_importances_          # Array of importance scores (sum=1)
sorted_idx  = np.argsort(importances)[::-1]   # Sort high to low

print("Feature Importances:")
for i in sorted_idx:
    print(f"  {feat_names[i]:15s}: {importances[i]:.4f}")

# Permutation Importance — more reliable (but slower)
from sklearn.inspection import permutation_importance
perm = permutation_importance(rf, X_test, y_test, n_repeats=10, random_state=42)
print("\nPermutation Importance (test set):")
for i in np.argsort(perm.importances_mean)[::-1]:
    print(f"  {feat_names[i]:15s}: {perm.importances_mean[i]:.4f}")
MDI vs Permutation Importance — Which to Use?
MDI (Mean Decrease in Impurity) = rf.feature_importances_:
Fast, built-in. Lekin biased toward high-cardinality features (zyada unique values wale features).

Permutation Importance = permutation_importance():
Slower but more reliable. Har feature ko randomly shuffle karo → test performance drop kitni = importance.

Production ke liye: dono calculate karo, compare karo. Consistent features = truly important!
🤔 Random Forest mein ek feature ki importance = 0.42 hai aur dusre sab features ki importance < 0.1 hai. Is information ka best practical use kya hai?
AFeature selection karo — low importance features drop karo aur domain experts ko batao kaunsa factor most predictive hai
BUs dominant feature ko drop karo — zyada importance = multicollinearity
CModel ki accuracy directly isse pata chalti hai
DRegularization badhao — dominant feature = overfitting signal
