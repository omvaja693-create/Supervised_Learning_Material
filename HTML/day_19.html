Section 01Overview

Questions ki Chain se Class Prediction

Decision Tree Classifier supervised learning algorithm hai. Ye features par questions pooch kar data ko smaller groups mein divide karta hai. Har internal node ek condition, har branch uska outcome, aur har leaf final class distribution represent karta hai.

Binary aur multiclass classification dono possible hain. Logistic Regression ek global linear boundary seekhta hai; tree multiple feature-threshold rules se piecewise regions banata hai.

Example ruleStudy hours ≤ 4? Agar yes, attendance ≤ 75% check karo. Agar no, doosre branch par jao. Leaf par Pass/Fail prediction milti hai.
Non-Technical Example: Parcel Sorting

Courier desk questions poochta hai: weight ≤ 2 kg? Fragile hai? Local delivery hai? Har answer next branch choose karta hai. Final counter leaf jaisa hai. ML tree ke questions manually fixed nahi hote: training data se learn hote hain.

Section 04How the Tree Learns Splits

Greedy Recursive Partitioning

  1. Current node par candidate features and thresholds consider karo.
  2. Har split ke left/right child class counts calculate karo.
  3. Weighted child impurity compare karo.
  4. Best allowed reduction wala split choose karo.
  5. Child nodes par process repeat karo, stopping constraints tak.

Greedy ka meaning: current node par best split choose hota hai. Ye globally optimal entire tree ki guarantee nahi deta. Scikit-learn CART-style binary splits use karta hai: har split ke two children.

Numeric exampleFeature values 2, 4, 6, 8 hain to thresholds 3, 5, 7 candidates ho sakte hain. Split x ≤ 5 first two rows left aur remaining right bhejta hai.

Section 05Gini, Entropy & Information Gain

Impurity = Class Mixing

Pure node mein sirf ek class hoti hai, impurity 0. Mixed node mein uncertainty higher hoti hai. pₖ node mein class k ka proportion hai; K total classes.

Gini impurityG=1−∑k=1Kpk2
Entropy in bitsH=−∑k=1Kpklog2(pk)

0 log₂ 0 ko limit se 0 treat karte hain. Binary 50/50 node ka Gini 0.5 aur entropy 1 bit hota hai. Ye values interchangeable nahi hain; dono different impurity measures hain.

Local impurity reductionΔI=Iparent−(nLnIL+nRnIR)

Entropy-based reduction ko information gain kehte hain. Same candidate splits ko Gini aur entropy different order mein rank kar sakte hain.

Section 06Worked Split Calculation

Technical Example: 10 Training Samples

Parent: 6 Pass, 4 Fail. Gini = 1 − (0.6² + 0.4²) = 0.48.

Candidate splitLeftRightWeighted GiniReduction
A4 Pass, 1 Fail; G = 0.322 Pass, 3 Fail; G = 0.480.5×0.32 + 0.5×0.48 = 0.400.08
B5 Pass, 0 Fail; G = 01 Pass, 4 Fail; G = 0.320.5×0 + 0.5×0.32 = 0.160.32

Candidate B bigger impurity reduction deta hai. Constraints allow karein to tree B choose karega. Child sizes unequal hon to 0.5 weights use nahi karne: actual nL/n and nR/n use karo.

Section 07Overfitting & Pruning

Deep Tree Training Data Memorize Kar Sakta Hai

Unrestricted tree noisy patterns ko isolate karke training accuracy high kar sakta hai. New data par performance gir sakti hai. Bahut shallow tree underfit bhi kar sakta hai.

Pre-Pruning

Growth ke time restrictions: max_depth, min_samples_leaf, min_samples_split, max_leaf_nodes.

Post-Pruning

Cost-complexity pruning ccp_alpha se low-value branches remove hoti hain. Larger alpha generally smaller tree encourage karta hai.

Cost-complexity objectiveRα(T)=R(T)+α×leaf_count(T)

R(T) leaf impurity ka weighted total hai; alpha complexity penalty control karta hai. Parameters training folds ke cross-validation par tune karo; final test set ek final evaluation ke liye reserve rakho.

Strengths and Limits

Tree ko numeric scaling usually zaroori nahi, nonlinear feature interactions learn kar sakta hai, aur rules inspect kar sakte ho. Single trees unstable ho sakte hain: data mein small change tree ko change kar sakta hai. Predictions axis-aligned piecewise regions se aati hain; probability calibration guaranteed nahi.

Categorical inputs ke liye suitable encoding pipeline use karo. Feature importance ka high score causal proof nahi; impurity-based importance high-cardinality features ko favor kar sakti hai. Held-out permutation importance useful cross-check hai.

Section 10Python Project: Iris Classifier

Iris built-in dataset mein 150 samples, four flower measurements aur three species hain. External CSV download ki zaroorat nahi. Ye code training split par stratified cross-validation se tree choose karta hai aur held-out test par evaluate karta hai.

train_and_evaluate.py
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split, StratifiedKFold, GridSearchCV
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.metrics import classification_report, confusion_matrix

data = load_iris(as_frame=True)
X, y = data.data, data.target
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
search = GridSearchCV(
    DecisionTreeClassifier(random_state=42),
    {"max_depth": [2, 3, 4, None],
     "min_samples_leaf": [1, 3, 5],
     "ccp_alpha": [0.0, 0.01, 0.03]},
    scoring="f1_macro", cv=cv
)
search.fit(X_train, y_train)
model = search.best_estimator_
pred = model.predict(X_test)
print("Best parameters:", search.best_params_)
print(confusion_matrix(y_test, pred, labels=model.classes_))
print(classification_report(
    y_test, pred, labels=model.classes_,
    target_names=data.target_names, zero_division=0
))
print(export_text(model, feature_names=list(X.columns)))
visualize_and_predict.py
import matplotlib.pyplot as plt
from sklearn.tree import plot_tree
from sklearn.metrics import roc_auc_score

plt.figure(figsize=(14, 8))
plot_tree(model, feature_names=list(X.columns),
          class_names=list(data.target_names),
          filled=True, rounded=True)
plt.tight_layout()
plt.show()

new_row = X_test.iloc[[0]]
prob = model.predict_proba(new_row)[0]
for class_id, p in zip(model.classes_, prob):
    print(data.target_names[class_id], round(p, 3))
print("Predicted:", data.target_names[model.predict(new_row)[0]])

# Multiclass AUC uses probabilities, not predicted labels.
auc = roc_auc_score(
    y_test, model.predict_proba(X_test),
    multi_class="ovr", average="macro", labels=model.classes_
)
print("Macro OvR ROC-AUC:", auc)
Read output carefullyconfusion_matrix mein rows actual classes aur columns predicted classes hain. predict_proba column order classes_ follow karta hai. Leaf probability observed training proportion hai; perfect confidence ka guarantee nahi.

Section 11Common Mistakes & Revision

  • Training accuracy ko final success samajhna: test/CV metrics compare karo.
  • Feature scaling mandatory samajhna: trees numeric threshold order par split karte hain.
  • Depth sirf increase karna: min_samples_leaf aur pruning bhi compare karo.
  • Test data par hyperparameters choose karna: evaluation information leak hoti hai.
  • Feature importance ko causal effect samajhna: association and importance causal proof nahi hain.
  • Imbalanced classes mein accuracy alone: per-class recall, macro F1, confusion matrix use karo.

Current API reference: DecisionTreeClassifier documentation. Tree mechanics and pruning: Decision Trees user guide.
