SVC ka IntuitionSupport Vector Classification

Support Vector Classification (SVC) Support Vector Machine family ka supervised classifier hai. Binary case mein classes ko separate karne wali decision boundary find karta hai, with a preference for a large margin and a controlled penalty for margin violations.

Non-technical example: do groups ke beech corridor
Room mein do student groups khade hain. Unke beech divider place karna hai. Sirf separation enough nahi: divider ke around spacious corridor bhi chahiye, so small position changes se group assignment immediately flip na ho. Closest students corridor constrain karte hain—support vectors ka intuition. Overlapping groups mein every student ko perfectly separate karna possible nahi, so some violations accept karni padti hain.

Linear boundary

2 features: line. 3 features: plane. Higher dimensions: hyperplane.

Kernel boundary

Non-linear relationships ke liye kernel similarity use karke original feature space mein curved boundaries possible hain.

SVM model family ka naam hai; scikit-learn mein SVC classifier aur SVR regressor hain. This lesson focuses on SVC.

5 W's: What, Why, When, How, WhereSupport Vector Classification

QuestionHinglish answer
What?Margin-based supervised classification model, with optional kernel similarity.
Why?Controlled boundary complexity aur strong linear/non-linear classification baseline.
When?Small-to-medium datasets, meaningful feature representation, and scaling-ready numeric features.
How?Scale features → select kernel/C/gamma with CV → fit margin-based model → predict.

Hyperplane, Margin & Support VectorsSupport Vector Classification

f(x)=wTx+b

Decision boundary f(x)=0 hai. Binary mathematical labels y ∈ {−1,+1} use karte hain. Positive score +1 side, negative score −1 side represent karta hai. Scikit-learn original class labels preserve karta hai.

SurfaceEquationMeaning
Decision boundarywᵀx + b = 0Class-separation hyperplane
Positive margin planewᵀx + b = +1Canonical positive margin
Negative margin planewᵀx + b = −1Canonical negative margin
Full margin width=2‖w‖

Canonical normalization mein ‖w‖ smaller ho toh margin wider. Support vectors non-zero dual coefficients wale influential training examples hain. Hard-margin optimum mein supporting samples margin par hote hain; soft-margin mein support vectors margin ke andar ya wrong side par bhi ho sakte hain.

“Only the closest points matter” useful starting intuition hai, complete soft-margin explanation nahi. Every margin-contact point stored support vector hona necessary nahi in degenerate solutions; support status solver ke learned coefficients se determine hota hai.

Hard margin assumes separable data and no margin violations. Noisy/overlapping data ke liye soft margin practical hai: allow slack ξ while penalizing violations.

C: Regularization Trade-offSupport Vector Classification

C margin-violation penalty ka multiplier hai, learning rate nahi. Other settings fixed hon toh small C violations ko cheaper banata hai; large C unhe more expensive banata hai.

Small C

Stronger regularization; often smoother/wider-margin solution, more violations tolerated. Too small → underfit.

Large C

Weaker regularization; violations par stronger pressure. Noise fit karne ka risk increase ho sakta hai, but perfect training separation guaranteed nahi.

C=[0.1,1,10] coarse starting search ho sakti hai. Best value dataset, scale, kernel aur metric par depend karti hai. Validation se choose karo.

C increase karna universally better accuracy nahi deta. Margin width aur test performance ka effect data-dependent hai, especially with non-linear kernels.

Kernels & GammaSupport Vector Classification

Kernel K(x,z) implicit transformed features ke dot product ko compute karta hai, without necessarily constructing those high-dimensional features explicitly. Isse original input space mein non-linear decision boundaries possible hain.

KernelSimilarityPractical notes
linearxᵀzSimple baseline; gamma irrelevant
rbfexp(−γ ‖x−z‖²)Local similarity; C and gamma tune
poly(γ xᵀz + coef0)^degreeDegree/gamma/coef0 influence complexity
sigmoidtanh(γ xᵀz + coef0)Less common; parameter choices need care
K(x,z)=e−γ‖x−z‖2

Low gamma

Broad influence radius; similarity drops slowly with distance. Too low may miss local structure.

High gamma

Narrow influence radius; local, potentially complex boundaries. Too high can overfit.

Example squared distance = 4: gamma 0.1 → exp(−0.4) ≈ 0.6703; gamma 1 → exp(−4) ≈ 0.0183. Higher gamma same separation ko much less similar treat karta hai.

Default SVC kernel rbf hai. gamma="scale" input variance aur feature count use karta hai; preprocessing ke baad supplied data par calculate hota hai. C aur gamma together tune karo.

Scaling, Multiclass & Decision ScoresSupport Vector Classification

SVC feature magnitudes se sensitive hai because geometry/kernel similarity scale-dependent hoti hai. Unequal units boundary distort kar sakte hain. StandardScaler + SVC Pipeline practical default workflow hai, not universal guarantee.

Scaling CV ke bahar full dataset par fit mat karo. Pipeline inside GridSearchCV har fold ke training-only statistics learn karta hai. App inference mein raw named input saved Pipeline ko pass karo.

Multiclass SVC

Scikit-learn SVC internally one-vs-one train karta hai. M classes ke liye M(M−1)/2 pairwise classifiers. Iris ke 3 classes → 3 pairwise models. Default decision_function_shape="ovr" output format hai; internal training strategy ko one-vs-rest mein convert nahi karta.

Scores ≠ probabilities

decision_function() signed confidence-like scores deta hai, values [0,1] mein constrained nahi. Binary linear geometric distance score/‖w‖ se milta hai; multiclass OVR-transformed scores ko raw geometric distances mat samjho.

Probability estimates chahiye toh training-only CalibratedClassifierCV use kar sakte hain. Calibration extra fitting cost introduce karta hai aur probabilities ka winning class uncalibrated predict() se differ kar sakta hai. Older examples ka SVC(probability=True) current API mein deprecated ho raha hai; is tutorial mein explicit calibration workflow use hota hai.

Python: Classification & Kernel SearchSupport Vector Classification

Dependency installation: pip install scikit-learn numpy. Run the three blocks in order. Iris ka 3-class dataset use karenge, with all 4 numeric features.

Python • 1. Leakage-safe SVC tuning
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split, StratifiedKFold, GridSearchCV
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.metrics import classification_report, confusion_matrix

data = load_iris(as_frame=True)
X, y = data.data, data.target
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, stratify=y, random_state=42
)
pipeline = Pipeline([
    ("scale", StandardScaler()),
    ("svc", SVC()),
])
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
search = GridSearchCV(
    pipeline,
    param_grid=[
        {"svc__kernel": ["linear"], "svc__C": [0.1, 1, 10]},
        {"svc__kernel": ["rbf"], "svc__C": [0.1, 1, 10],
         "svc__gamma": ["scale", 0.1, 1]},
    ],
    scoring="f1_macro", cv=cv, refit=True, n_jobs=1,
    error_score="raise",
)
search.fit(X_train, y_train)
best = search.best_estimator_
print("Best parameters:", search.best_params_)
print("Mean CV macro F1:", search.best_score_)
predictions = best.predict(X_test)
print(confusion_matrix(y_test, predictions))
print(classification_report(y_test, predictions, zero_division=0))

List-of-dictionaries grid avoids irrelevant gamma search for linear kernel. 3 linear + 9 RBF = 12 candidates; 5-fold CV → 60 fits + refit. Final test results ko grid refinement feedback mat banao.

Python • 2. Inspect support vectors & scores
model = best.named_steps["svc"]
print("Support vectors per class:", model.n_support_)
print("Total support vectors:", len(model.support_))

# support_ contains training-array positions, not original row labels.
original_support_rows = X_train.iloc[model.support_]
print(original_support_rows.head())
print("Transformed support-vector shape:", model.support_vectors_.shape)

sample = X_test.iloc[:1]
print("Predicted label:", best.predict(sample))
print("Decision scores:", best.decision_function(sample))
print("Class order:", model.classes_)
# Default multiclass decision scores use OVR output shape.
Stored support_vectors_ transformed/scaled space mein hain because SVC scaler ke baad fitted hai. Original reference rows ko X_train.iloc[model.support_] se inspect karo. Number of support vectors complexity/compute ka signal ho sakta hai, accuracy guarantee nahi.
Python • 3. Optional calibration & trusted export
from sklearn.calibration import CalibratedClassifierCV
from sklearn.base import clone
import pickle
import numpy as np

# Clone the FULL pipeline so scaling stays fold-local during calibration.
calibrated = CalibratedClassifierCV(
    estimator=clone(best), method="sigmoid", cv=3, ensemble=False
)
calibrated.fit(X_train, y_train)
probabilities = calibrated.predict_proba(X_test)
print("Probability class order:", calibrated.classes_)
print(probabilities[:2])
assert np.allclose(probabilities.sum(axis=1), 1.0)

artifact = {
    "model": calibrated,
    "features": list(X_train.columns),
    "class_names": list(data.target_names),
}
with open("iris_svc_pipeline.pkl", "wb") as file:
    pickle.dump(artifact, file)

# Only load a trusted artifact in the matching training environment.
with open("iris_svc_pipeline.pkl", "rb") as file:
    restored = pickle.load(file)

assert np.allclose(
    probabilities, restored["model"].predict_proba(X_test)
)
print("Export/load probability parity passed.")

This calibration block optional alternate final model hai. Deployment ke liye calibrated vs uncalibrated choice training-only validation se before final test decide karo. Calibrated output ko test-based retuning ke liye use mat karo. Hyperparameter selection and calibration together ki unbiased estimate chahiye toh nested validation use karo.

Pickle untrusted source se load mat karo. Matching package versions record karo. SVC artifact support-vector data retain kar sakta hai; private training data publish karne ka risk assess karo.

One-Minute Revision

Boundary f=0; canonical margins f=±1; width=2/‖w‖. Soft margin trades regularization and violations. C controls penalty; gamma controls kernel locality. Scale safely. Tune with CV. Scores ≠ probabilities. Multiclass SVC trains pairwise models.
