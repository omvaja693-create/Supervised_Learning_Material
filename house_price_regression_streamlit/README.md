# 🏠 House Price Regression — Streamlit Deployment

A complete beginner-friendly Machine Learning deployment project.

## What students learn

1. Load a regression dataset
2. Separate features and target
3. Train/test split
4. Missing-value handling with `SimpleImputer`
5. Feature scaling with `StandardScaler`
6. Build a Scikit-learn `Pipeline`
7. Train `LinearRegression`
8. Evaluate using MAE, MSE, RMSE and R²
9. Export the complete pipeline with `pickle`
10. Load the exported model in Streamlit
11. Build an interactive prediction form
12. Run the application locally
13. Deploy the project to Streamlit Community Cloud

## Project structure

## Step 1 — Create environment

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## Step 2 — Install packages

```bash
pip install -r requirements.txt
```

## Step 3 — Train/export the model

```bash
python train_model.py
```

This creates:

```text
model/house_price_pipeline.pkl
model/metrics.json
```

## Step 4 — Run Streamlit

```bash
streamlit run app.py
```

## Important concept: Pipeline

The exported `.pkl` contains both preprocessing and the trained model:

```text
Input
  ↓
SimpleImputer
  ↓
StandardScaler
  ↓
LinearRegression
  ↓
Prediction
```

Therefore, the Streamlit application does not manually call the scaler or imputer.

## Deployment

Push the project to a GitHub repository with at least:

```text
app.py
requirements.txt
model/house_price_pipeline.pkl
data/house_data.csv
```

Then create a Streamlit Community Cloud app and select:

```text
app.py
```

The `requirements.txt` file tells the deployment environment which Python packages to install.

## Important deployment note

The model file is generated by `train_model.py` and is already included in this project package so the Streamlit app can run immediately.

If you retrain the model, commit the newly generated:

```text
model/house_price_pipeline.pkl
```

to your repository before redeploying.
